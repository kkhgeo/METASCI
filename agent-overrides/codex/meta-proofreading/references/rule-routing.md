# Rule routing for meta-proofreading

All operative kernel references are bundled in this skill. No runtime access to a
development directory or another installed writing skill is required.

## Conflict resolution

Use this precedence:

1. source fidelity and research integrity;
2. current official venue/reporting requirements;
3. author scope and intended meaning;
4. Codex kernel;
5. manual and reviewer heuristics;
6. style preference.

A generic count, template, recent-year window, or citation norm is nonbinding unless
the target venue or genre requires it. An extraction is a navigation aid until its
load-bearing content is checked against an appropriate original.

## Consensus rule

Agreement raises confidence only to the extent that judgments are independent.
Shared prompts, shared manuals, or shared derived sources create correlated errors.
Rank by severity, evidence quality, and downstream impact before consensus category.
A supported minority finding remains visible.
