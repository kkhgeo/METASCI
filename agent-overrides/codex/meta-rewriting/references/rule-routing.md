# Rule routing for meta-rewriting

All operative kernel references are bundled in this skill. Runtime use must not
read the development kernel or depend on another installed writing skill.

## Load order

1. `codex-kernel-index.md`
2. `codex-process.md`
3. `codex-paragraph-logic.md`
4. `codex-section-structure.md` when the section is known
5. `codex-ai-era.md`
6. `principles.md`
7. `section-checklists.md` when section context affects the rewrite

## Rule application

| Revision decision | Primary rule family | Local detail |
|---|---|---|
| Preserve meaning and evidence | Process / AI-era | `SKILL.md` preservation diff |
| Repair controlling point and flow | Paragraph logic | `principles.md` |
| Respect section function | Section structure | `section-checklists.md` |
| Calibrate claims | Process / paragraph logic | `principles.md` |
| Avoid formulaic AI prose | AI-era | Expression pass in `SKILL.md` |

## Conflicts and exceptions

Use this precedence:

1. source fidelity and research integrity;
2. official venue or reporting requirements;
3. explicit user instruction;
4. Codex kernel;
5. local heuristics and examples;
6. stylistic preference.

Generic word counts, paragraph counts, and move sequences are examples unless the
current venue makes them requirements. Fluency never authorizes a factual,
numerical, causal, or attribution change.

If a rule admits several defensible phrasings, select the one closest to the
author's meaning and voice. Generate alternatives only when the distinction is
useful to the author.
