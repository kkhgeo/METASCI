# Visual Slides

Use visual mode for live talks where comprehension, attention, and memory matter more than handout completeness.

## Purpose

Visual slides support the speaker. They should make the audience see the idea before reading the details.

## Default Rules

- One idea per slide.
- One dominant visual object.
- Title is a clear keyword or noun phrase; the takeaway appears as a separate short lead statement or callout.
- Body text usually stays under 50 words.
- Use large type, high contrast, and generous whitespace.
- Prefer visuals that reveal relationships: flow, map, network, scale, before/after, contrast, timeline, hierarchy, or system boundary.

## Visual Transformations

- Bullet list -> three-part process, matrix, or icon row.
- Dense paragraph -> keyword title + lead statement + annotated diagram.
- Table -> highlighted comparison, ranked list, or small multiples.
- Method description -> pipeline with named stages.
- Abstract concept -> metaphor diagram plus one definition line.
- Result paragraph -> chart/map with direct callout.
- Framework slide -> simplified architecture with upstream inputs and downstream decision value.

## Speaker Notes Strategy

Move detail out of the slide when:

- It explains background the speaker can say.
- It is a caveat not needed for first comprehension.
- It is a citation trail better suited to backup slides.
- It repeats the visual.

Keep detail on the slide when:

- The deck must be read without the speaker.
- The claim is technical and precision matters.
- The audience will need to quote or reuse the content.

## Progressive Reveal

Use reveal or slide sequence for reasoning chains:

1. Start with the problem state.
2. Add the organizing principle.
3. Add the mechanism.
4. Add the result or implication.

Do not reveal randomly. Each reveal should answer "what changed in the audience's understanding?"

## Review Checklist

- Can the audience identify the main idea in 2 seconds?
- Does the title identify the topic clearly, and does the lead statement say what to conclude?
- Is there one dominant visual hierarchy?
- Is any text competing with the visual?
- Would removing a bullet improve attention without losing meaning?
- Is the visual specific to the topic, not a generic decoration?
