1. **당위적 표현 밀도 급증**: 서론(중간) -> 미래담론(중간) -> 발전전략(높음) -> 맺음말(매우 높음). 후반부로 갈수록 ~해야 한다, ~이 필요하다, ~(이) 요구된다 표현이 압도적으로 증가한다.

2. **인용 밀도 및 유형 변화**: 서론(법률 인용+소수 학술) -> 미래담론(학술 인용 집중, 통합형+비통합형 혼용) -> 발전전략(국내 연구 인용 중심) -> 맺음말(최소 인용). 논의 심화 구간에서 학술 인용이 집중되고, 결론으로 갈수록 저자 자신의 종합적 판단이 증가한다.

3. **어휘 추상화 수준**: 서론(구체적 법률명·수치) -> 미래담론(이론적 개념어: 패러다임, 거버넌스, 합법성) -> 발전전략(실행적 한자어: 고도화, 내실화, 환류) -> 맺음말(가치 지향 어휘: 실천적, 진지하게, 경청). 섹션에 따라 어휘의 추상화 수준과 방향성이 뚜렷이 변화한다.

|---------|---------|----------|--------|

| Category | Ratio | Examples |
|----------|-------|---------|
| **한자어 (Sino-Korean)** | ~75% of key vocabulary | 환경평가, 지속가능발전, 패러다임, 거버넌스, 합법성, 의사결정, 투명성, 공정성, 신뢰성, 제도, 전략, 방향, 성과, 역할, 고도화, 내실화 |
| **고유어 (Native Korean)** | ~15% of key vocabulary | 짚어보다, 끌어내다, 다가오다, 이루다, 갖추다, 마주하다, 벗어나다, 떠나다, 이끌다 |
| **외래어 (Loanwords)** | ~10% of key vocabulary | 패러다임, 거버넌스, 메가트렌드, 뉴노멀, 시스템, 플랫폼, 디지털, 메타버스 |

#### H.1.4 연결어미 패턴 (Connective Endings)

| Connective Ending | Function | Example | Source |
|-------------------|----------|---------|--------|
| **~하며** | 병행/동시 | 국가 단위의 환경관리로 규제하지 못하는 실정이다 + 국제적인 생산·소비 활동에서 비롯**하며** | [EX#1-미래담론] |
| **~하고** | 나열 | 환경평가제도를 도입**하고**, 단일법으로 | [EX#1-서론] |
| **~하여** | 원인/순서 | 독립적으로 제정(1993년)**하여** 개정(2012년)에 따라 | [EX#1-서론] |
| **~함으로써** | 수단/방법 | 성과를 증명**함으로써** 환경평가의 잠재력을 끌어낼 것을 | [EX#1-미래담론2.1] |
| **~면서** | 동시/병행 | 성과와 경험을 축적하**면서** 제도적으로 점진적인 발전을 | [EX#1-서론] |
| **~(으)므로** | 이유/근거 | 법제화하고 있**으므로** 여러 분야를 포괄 또는 다양한 | [EX#1-발전전략3.1] |
| **~더라도** | 양보 | 제도를 정비하**더라도** 환경영향에 대한 불확실성을 고려하면 | [EX#1-미래담론2.3] |
| **~지만** | 대조/양보 | 달성 시기가 다가오고 있**지만**, 파리협약 목표 달성이 어려울 | [EX#1-서론] |
| **~도록** | 목적/결과 | 의사결정이 도출되**도록** 제도의 투명성과 신뢰성을 확보해야 | [EX#1-서론] |

| Pattern | Function | Example | Source |

| Ending | Function | Frequency | Example | Source |

### H.2 Do / Don't Rules (per section)

| Section | Do | Don't |
|---------|----|-------|
| **1. 서론** | DO: 해라체(~이다/~있다)로 객관적 배경을 기술한다. Evidence: "환경평가는 지속가능발전목표 아래 친환경적인 개발을 도모하는 계획 도구이자 환경정책 입안 도구이다." [EX#1-서론] | DON'T: 합쇼체(~입니다/~합니다)를 본문에 사용하지 않는다. 안내 문구에만 1회 사용. |
| **1. 서론** | DO: 법률명은 꺾쇠 「」를 사용하여 인용한다. Evidence: "「국가환경보호법(NEPA)」(1969년)" [EX#1-서론] | DON'T: 법률명을 따옴표(' ')로 인용하지 않는다. |
| **1. 서론** | DO: 영문 약어는 첫 등장시 한글(영문약어) 형태로 병기한다. Evidence: "지속가능발전목표(SDGs)" [EX#1-서론] | DON'T: 약어를 설명 없이 사용하지 않는다. |
| **1. 서론** | DO: 목적 진술 시 ~고자 한다 패턴을 사용한다. Evidence: "전략을 제안하고자 한다" [EX#1-서론] | DON'T: 1인칭 '나'를 사용하지 않는다. '우리' 또는 비인칭으로 서술한다. |
| **2. 미래 담론** | DO: 상반된 학술 관점을 대비시켜 서술한다. Evidence: 혁신주의 vs 진화주의 대비 구조 [EX#1-미래담론2.1] | DON'T: 한쪽 관점만 제시하고 반론을 무시하지 않는다. |
| **2. 미래 담론** | DO: 학술 인용 시 통합형과 비통합형을 혼용한다. Evidence: "Partidario(2020)는 ~를 제안하고 있다" + "(Hacking, 2018)" [EX#1-미래담론] | DON'T: 모든 인용을 하나의 형태로만 처리하지 않는다. |
| **2. 미래 담론** | DO: 문제 분석 시 ~할 수 있다/~할 수밖에 없다로 가능성과 불가피성을 구분한다. Evidence: "기회를 창출할 수 있다" vs "자원고갈을 마주할 수밖에 없다" [EX#1-미래담론] | DON'T: 모든 가능성을 동일한 확실성으로 서술하지 않는다. |
| **3. 발전 전략** | DO: 전략 제시 시 ~해야 한다/~이 필요하다 패턴을 적극 사용한다. Evidence: "건설적 해법을 도출해야 한다" [EX#1-발전전략3.1] | DON'T: 전략 섹션에서 지나치게 모호한 표현(~일 수도 있다)을 남용하지 않는다. |
| **3. 발전 전략** | DO: 전략을 번호/글머리 기호로 구조화한다. Evidence: 7개 미래 방향 항목을 글머리표(●)로 나열 [EX#1-발전전략3.1] | DON'T: 전략을 산문 형태로만 나열하지 않는다. |
| **3. 발전 전략** | DO: 그림/표를 활용하여 전략 체계를 시각화한다. Evidence: [그림 3] 뉴노멀 시대의 환경평가제도 발전전략, [표 4] 중장기 연구과제 [EX#1-발전전략3.2] | DON'T: 전략 체계를 텍스트로만 설명하지 않는다. |
| **4. 맺음말** | DO: 서론의 핵심 문장을 변주하여 반복한다. Evidence: 서론 "직면하고 있음이 분명하다" → 맺음말 첫 문장 동일 표현 반복 [EX#1-맺음말/서론] | DON'T: 완전히 새로운 논점을 맺음말에서 도입하지 않는다. |
| **4. 맺음말** | DO: 비유적 표현을 인용하여 강조한다. Evidence: "수염고래에서 날렵하고 위협적인 상어로 변모해야 한다" [EX#1-맺음말] | DON'T: 맺음말에서 지나치게 학술적 용어만 나열하지 않는다. |

| 일반어 (Generic) | 정책 학술어 (Policy-Academic) | Section | Usage Note |
|---------------|--------------------------|---------|------------|
| 중요한 | 핵심적인 / 실질적인 | 전체 | 정책 문서에서는 '중요한'보다 구체적 수식어 선호 |
| 만들다 | 구축하다 / 창출하다 / 도출하다 | 발전전략/맺음말 | 체계→구축, 기회→창출, 결과→도출 |
| 필요하다 | 요구된다 / 필수적이다 | 발전전략 | 피동형 '요구된다'가 더 격식적 |
| 쓰다/사용하다 | 활용하다 / 이행하다 | 전체 | '활용'은 도구적 사용, '이행'은 의무적 실행 |
| 바꾸다 | 전환하다 / 개선하다 / 변화시키다 | 미래담론 | 근본적→전환, 부분적→개선 |
| 높이다 | 고도화하다 / 제고하다 / 강화하다 | 발전전략 | 수준→고도화, 가치→제고, 제도→강화 |
| 살펴보다 | 검토하다 / 고찰하다 / 분석하다 | 서론/미래담론 | 격식 수준: 살펴보다 < 검토하다 < 고찰하다 |
| 생각하다 | 고민하다 / 고려하다 / 사고하다 | 미래담론 | '진지하게 고민하다'가 정책 문서에서 자연스러움 |

| 문제 | 과제 / 현안 / 쟁점 | 전체 | 과제(해결할 일), 현안(당면 문제), 쟁점(논쟁점) |

## I. Appendix: Key Structural Patterns Summary

### I.1 Korean Policy Review Document Architecture

```
1. 서론 (Introduction)
   - 주제 정의 → 역사적 배경 → 현황 → 문제 인식 → 필요성 → 목적 진술

2. [주제] 미래 담론 (Future Discourse)
   - 2.1 하위주제1 (e.g., 패러다임 전환)
   - 2.2 하위주제2 (e.g., 다원주의 거버넌스)
   - 2.3 하위주제3 (e.g., 의사결정의 합법성)
   - 2.4 하위주제4 (e.g., 지속가능발전목표 통합)
   * 각 하위 절: 국제 동향 → 이론/관점 정리 → 국내 적용 → 시사점

3. [주제] 발전 전략 (Development Strategy)
   - 3.1 미래 방향 (종합 + 글머리표 나열)
   - 3.2 중장기 발전 전략 (과거 전략 요약 → 새 비전 → 핵심전략 → 세부과제)
   * 그림/표로 전략 체계 시각화

4. 맺음말 (Conclusion)
   - 서론 핵심 반복 → 담론 종합 → 전략 재확인 → 최종 강조
   * 당위적 표현 최대 밀도
```
