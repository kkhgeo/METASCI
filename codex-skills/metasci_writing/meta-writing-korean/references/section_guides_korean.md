# 국문 섹션별 내용 작성 지침

이 파일은 `meta-writing-korean`의 초안 작성 단계에서 해당 섹션 부분만 읽는다.
목표는 **내용 기능에 맞는 명료한 작업 초안**이다. 문장별 발전적 편집과 개인 문체
적용은 `meta-rewriting-korean`의 책임이다.

---

## 공통 원칙

### 레지스터와 종결체

- 학술 논문과 기관·정책 보고서 모두 본문은 격식체를 기본으로 한다.
- 기존 원고나 발주처 양식이 있으면 그것을 우선한다.
- 명사화·피동·당위 표현은 그 자체로 결함이 아니다. 주체와 관계를 흐릴 때만 고친다.

### 단락과 문장

- 단락마다 주된 기능을 하나 정하되 문장 수를 기계적으로 맞추지 않는다.
- 주제문은 독자의 진입을 돕는 위치에 둔다. 모든 단락을 같은 두괄식 틀로 만들지 않는다.
- 한 문장에는 하나의 주명제를 두되, 조건·근거·한계가 긴밀하면 종속적으로 결합할 수 있다.
- 접속어는 실제 논리관계가 문면에서 불분명할 때만 쓴다. 사용 횟수 목표를 두지 않는다.
- 문장 길이는 정보량과 기능에 따라 달리한다. 장문이나 단문을 일부러 만들지 않는다.
- 지시어는 선행사가 분명할 때 허용한다. 모호하면 핵심 개념을 다시 쓴다.

### 인용 원칙

인용 수의 최소·최대값을 두지 않는다. 외부 주장마다 가장 직접적인 근거가 있는지,
인용이 주장 범위와 강도를 실제로 지지하는지를 본다.

- `author_data`: 표·그림·자료 번호로 지시
- `external_dataset`: 생산기관·자료명·연도 인용
- `literature`: 저자·연도 인용
- `policy_legal`: 공식 문서명·연도·필요시 조문 확인
- `user_notes`: 근거가 없으면 저자 판단 또는 확인 필요로 표시

### 보고 동사

| 기능 | 예 | 주의 |
|---|---|---|
| 선행문헌의 행위 | 보고하였다, 분석하였다, 관찰하였다, 제안하였다 | 실제 행위에 맞춘다 |
| 자기 자료의 표시 | 나타났다, 증가하였다, 차이를 보였다 | 자료가 말하는 범위만 쓴다 |
| 자기 해석 | 시사한다, 해석된다, 가능성이 있다 | 근거 수준에 맞춰 강도를 정한다 |
| 표·그림 지시 | 나타낸다, 제시한다 | `입증한다`로 자동 치환하지 않는다 |

동사를 다양하게 보이게 하려고 의미가 다른 동사로 바꾸지 않는다.

### 시제

| 대상 | 기본 시제 |
|---|---|
| 이 연구가 수행한 방법과 관찰된 결과 | 과거 |
| 확립된 일반 지식 | 현재 |
| 표·그림이 현재 문서에서 보여주는 내용 | 현재 |
| 선행연구의 특정 수행·발견 | 과거 또는 원고 관행 |

## 학술 논문

### 서론

배경을 넓게 나열하기보다 연구문제로 수렴한다.

1. 연구대상과 맥락
2. 관련 지식과 현재 접근
3. 해결되지 않은 문제 또는 방법적 한계
4. 그 공백이 왜 중요한지
5. 연구목적·질문·가설

이 순서는 기능 목록이지 고정 문장 틀이 아니다. 공백을 과장하거나 선행연구를
일률적으로 부정하지 않는다.

### 방법

재현 가능성이 우선이다.

- 대상, 기간, 표본, 장비, 전처리, 분석법, 소프트웨어, 판정기준을 제공된 자료대로 쓴다.
- 없는 사양은 `[확인 필요: 항목]`으로 남긴다.
- 방법 안에 결과나 장점을 미리 넣지 않는다.
- 피동은 절차의 초점을 유지할 때 자연스럽지만 주체가 중요하면 능동으로 쓴다.

### 결과

기본값은 `data-only`이다.

- 질문 또는 비교축 → 핵심 패턴 → 대표 수치 → 표·그림 지시 순으로 구성한다.
- 표 전체를 산문으로 복제하지 않는다.
- 원인·기전·정책적 의미는 고찰로 보낸다.
- 사용자가 `with-comparison`을 요구하면 선행연구와의 수치·방향 비교까지만 포함하고,
  원인 설명은 근거가 있을 때만 쓴다.
- 통계적 유의성과 실질적 크기를 구별한다.

### 고찰

가능한 기능은 다음과 같다.

- 핵심 결과의 의미
- 선행연구와의 일치·차이
- 가능한 기전과 대안 설명
- 적용 범위와 불확실성
- 연구의 한계
- 학술적·실무적 함의

모든 기능을 한 단락에 넣지 않는다. 인과·기전 진술은 특정 근거와 연결하고,
대안 설명이 있으면 함께 검토한다. 자료보다 강한 `입증한다·증명한다`는 피한다.

### 결론

- 연구질문에 대한 답과 핵심 함의를 압축한다.
- 본문에 없던 결과·기전·정책 제안을 새로 넣지 않는다.
- 인용 여부는 학술지 관행과 결론의 기능을 따른다. 무조건 금지하거나 강제하지 않는다.

## 기관·정책 보고서

보고서는 문서 목적에 따라 현황, 문제, 원인, 역할, 대안, 이행조건, 결론 중 필요한
기능을 선택한다. `현황→문제→방안`은 흔한 골격이지만 모든 절에 강제하지 않는다.

- 법령·정책·통계의 귀속을 명시한다.
- 당위 표현은 권고 주체와 적용 범위가 분명할 때 쓴다.
- 명사화와 피동은 기관 문체에서 허용하되 행위자·책임·조건을 감추지 않는다.
- 개조식은 비교·요약·과제 제시에 쓸 수 있다. 규범적 내용은 주체와 행위가 드러나는
  완전한 문장으로 쓴다.
- 특정 전환어·핵심 동사·문장 길이의 빈도 목표를 충족하려고 문장을 만들지 않는다.
- `보여준다`를 `입증한다`로, `필요하다`를 `요구된다`로 기계적으로 치환하지 않는다.

## 그림·표·데이터 해석

1. 축, 단위, 범례, 표본, 비교집단을 확인한다.
2. 가장 중요한 패턴·방향·차이·불확실성을 기술한다.
3. 대표 수치와 분모·단위를 함께 쓴다.
4. 외부 데이터면 생산기관과 자료를 인용한다.
5. 그림에서 읽은 값은 근사값으로 표시하고, 원자료가 있으면 원자료를 사용한다.
6. 관찰과 해석을 분리한다.
