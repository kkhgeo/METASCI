# meta-writing-mapping — 글 구성 논의

원고의 **섹션·단락 배치를 사용자와 논의**하는 스킬. 문장은 쓰지 않는다.
산출물은 작업 폴더의 `outline.md` 하나다. 이 파일은 **이 스킬 안에서 다시
읽히기 위한 것**이다 — 재조망 때 원자료를 다시 읽지 않게 해준다.

## 하는 일 / 안 하는 일

| 한다 | 안 한다 |
|---|---|
| 섹션·단락 배치를 논의하고 확정 | 본문 문장 작성 → `meta-writing` |
| 자료 정독 후 근거를 단락에 배정 | 문장 교정 → `meta-proofreading` |
| 근거 없는 단락을 웹 검색으로 보완 | 문체 손질 → `meta-styling` |
| 구조 결함을 규칙 근거로 지적 | 단락 재작성 → `meta-rewriting` |

## 진행 원칙 — 이 스킬의 핵심

1. **모드를 묻지 않는다.** 초안이 있는지, 전체인지 섹션인지는 폴더를 보면
   안다. 사용자에게 선언을 요구하지 말고 판단해서 먼저 말을 건다.
2. **본 것을 먼저 말한다.** 첫 응답은 "폴더에 무엇이 있고, 무엇이 이 원고의
   중심으로 보이는가" + **결정적인 질문 하나**. 질문 목록을 늘어놓지 않는다.
3. **지적에는 규칙 이름을 댄다.** "Gap 단락이 없다", "Methods↔Results 대응이
   깨졌다"처럼 `references/rule-routing.md`가 지정한 규칙을 근거로 말한다.
   추상적 조언("흐름이 어색하다")은 금지.
4. **표는 필요한 순간에만.** 대화가 주(主), 표는 정리 수단이다. 논의가 한
   단락 이상 쌓였거나 사용자가 전체를 보고 싶어 할 때만 꺼낸다.
5. **저장은 물어본다.** `outline.md`를 만들거나 고치기 전에 확인한다.
6. **근거 없는 단락은 설계 결함이다.** 집필로 미루지 않는다. 웹 검색으로
   보완을 시도하되 **한 단락당 검색 2회까지**다. 못 찾으면 `⚠ 근거없음`으로
   두고 단락 삭제나 범위 축소를 제안한다 — 계속 찾지 않는다. 사용자가 가진
   자료를 물어보는 것이 세 번째 검색보다 낫다.
7. **사용자 판단이 규칙을 이긴다.** 근거를 대고 한 번 반대하되, 재확인하면
   따르고 그 결정을 `outline.md`에 기록한다.

## 시작 절차

1. 작업 폴더 스캔 — `outline.md`, 초고(.docx/.md/.tex), `figures/`, `tables/`,
   `knowledge/`, `pdf/`.
2. `outline.md`가 있으면 읽는다. **근거 노트에 이미 있는 자료는 다시 읽지 않는다.**
3. 없으면 **그림·표는 직접 열어 판독하고 문헌은 정독한다.**
4. 본 것을 한 문단으로 말하고, 가장 결정적인 것 하나를 짚어 묻는다.

> **Claude:** 그러면 Discussion이 비어버릴 위험이 있습니다. Chen2024가 유사

> 안전한 선입니다. 그리고 쓰다 만 Intro는 배경 → 선행연구 → 목적인데
> **Gap 단락이 없습니다.** 급감을 아무도 설명 못 했다는 말이 없어서 목적 단락이
> 왜 필요한지가 안 섭니다.

모드를 묻지 않았고, 지적에 규칙 이름을 댔고, 표를 꺼내지 않았다.

## 세 가지 진입 — 선언 없이 판별

| 신호 | 상황 | 첫 동작 |
|---|---|---|
| 초고 파일 없음, 재료만 | 백지 설계 | 재료 정독 → 중심 근거 확인 → 섹션 뼈대부터 |
| 초고 파일 있음 | 구조 진단 | 역추출 → 기능 태그·논리관계 부여 → 결함 지적 |
| 섹션 이름을 지목 | 부분 작업 | `outline.md`로 전체 맥락 확보 → 그 섹션만 펼침 |
| 재료도 주제뿐 | 주장 잡기 | 표로 내려가지 말고 Core message 한 줄부터 합의 |

섹션 사이를 오르내리는 것은 자연스럽다. 전체를 보다 Results로 내려가고 다시
올라오는 동안 같은 `outline.md`를 고친다.

**언어** — 대화·해설은 한국어. 표의 한 줄 논지는 원고 언어를 따른다(영어
논문이면 영어 — 그대로 topic sentence의 씨앗이 되므로).
