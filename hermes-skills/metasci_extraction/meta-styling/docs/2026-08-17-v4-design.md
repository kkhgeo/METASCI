# meta-styling v4.0 — Design Spec

**Date**: 2026-08-17
**Status**: approved for implementation
**Supersedes**: v3.0.0 (2026-08-17, same day — see §1)

---

## 1. Why v4

### 1.1 The root contradiction

`metasci-style-extraction` v3.0 instructs every card to carry this rule:

> **Numbers diagnose; they do not set targets.** Report a measured rate as an observation,
> never as a value a draft should be edited toward. A rate is the result of other choices,
> not a handle.

`meta-styling` v3.0 Phase 3 does exactly the forbidden thing:

> `Measured gap` vs a soft/firm band → **apply** … move it **toward** the card's value

The producer forbids what the consumer does. Every v3.0 refinement (confidence tiers,
band widening, short-draft correction) was a correction *along the wrong axis*.

### 1.2 Measured evidence that the wrong axis fails

Test: 112-token Methods draft, corpus `style_corpus` (N=1, `kim-2015-nitrate-iso`).

v3.0 verification returned `ALL DIMENSIONS IN BAND`:

| dim | before | after | effective band | status |
|---|---|---|---|---|
| avg_sent_len | 13.9 | 22.4 | 21.2–47.7 | OK |
| hedges/1k | 13.1 | 8.9 | 5.7–12.8 | OK |
| passive/1k | 6.5 | 26.8 | 13.6–30.7 | OK |
| Red-Flag hits | 11 | 0 | 0 | OK |

The same passing text, checked against the card's own list of the author's distinctive
moves:

| distinctive move (from `card.md`) | present in the "passing" revision |
|---|---|
| Assumption-Rider (`assuming that`, clause-final, unflagged) | **no** |
| Therefore-Decision closer (`regardless of`) | **no** |
| Impersonal-It-Judgement (14× — the paper's most repeated Z shape) | **no** |
| paragraph closing on a decision rather than a finding | **no** |
| reporting-verb lane discipline | incidental (1 correct use, not prescribed) |

**A verifier that passes text carrying none of the target style is worse than no
verifier** — it reports success to the user.

### 1.3 Structural cause

v3.0 was built around what a script can check. Consequence:

```
measurable (3 numbers)   →  became the axis of prescription
not measurable           →  "qualitative" → "choice point" → at N=1, "mentioned, not applied"
```

Everything valuable the extraction found sits on the right-hand side: paragraph-function
spine, decision-closers, gap-as-method-defect, reporting-verb lanes, clause-final
assumption riders, the coined-term device replacing a Limitations section.

Consumption measured: `card.md` + `manifest.json` only. `logic.md` (682 lines),
`style-vocab.md` (355), `anchors.txt`, `wordlist.tsv` are referenced **zero** times —
about 13% of the extraction is used.

### 1.4 Requirement deleted rather than implemented

`aggregate.md` originally stated the intended consumer behaviour:

> downstream `meta-styling` applies cards in parallel — **laying out candidates and
> recommending one** — rather than reading a merged profile.

v2.0 and v3.0 never implemented candidates. On 2026-08-17 that sentence was removed from
`aggregate.md` to resolve the mismatch. That was the wrong direction; v4.0 restores the
requirement and `aggregate.md` must be reverted on this point.

## 2. Goals and non-goals

### Goals

- **G1** Prescribe from a *representation comparison* (paragraph function, sentence role,
  frame type, lane discipline), not from metric gaps.
- **G2** Improve the three things the user named: **logic**, **word choice**, **style** —
  logic via paragraph/sentence-role structure, which v3.0 explicitly disclaimed.
- **G3** Consume `logic.md` and `style-vocab.md`, not only the card.
- **G4** Keep every stage's context small and isolated; no stage holds a 70KB reference
  file except the one worker that reduces it.
- **G5** Produce **2–3 candidate revisions** with a recommendation and a reason.
- **G6** Be re-enterable: re-run any stage without redoing the ones before it.

### Non-goals

- **NG1** Judging whether the draft's argument is *sound* — that stays `meta-review`.
  v4.0 asks only "does this draft's structure match this reference's structure".
- **NG2** Deciding section order or outline for a manuscript — that stays
  `meta-writing-mapping`.
- **NG3** Removing AI-writing traces — stays `meta-rewriting-antiai`.
- **NG4** Merging references into a house style — still forbidden (see `aggregate.md`).
- **NG5** Altering claims, data, citations, or claim *direction*.

---

## 3. Architecture

Three axes, mutually dependent:

1. **Representation matching** replaces metric matching (§4–§6).
2. **File-backed staged pipeline** with parallel branches (§7).
3. **Multi-candidate generation + recommendation** (§8).

Numbers are demoted to a Stage 6 sanity check (§9). Tier gating from v3.0 is retained
unchanged (§10) — that part was correct.

---

## 4. Draft representation

Stage 1a tags the draft in the same taxonomy `logic.md` uses, making the two sides
diffable. Frame codes A1–L4 + Z are shared with `extraction-logic` and
`metasci-style-extraction`; do not invent new codes.

**Artifact: `1a-structure.md`**

```markdown
draft: my_methods.txt
section: M
tokens: 112
paragraphs: 3

## P1  function=Procedure  relation-to-next=Sequence
S1  role=Method     frame=E1  "A total of 88 groundwater samples were collected …"
S2  role=Reference  frame=F5  "Fig. 2 shows the sampling network …"

## P2  function=Procedure  relation-to-next=Sequence
…
```

Roles: Topic · Claim · Evidence · Elaboration · Example · Transition · Qualification ·
Reference · Method · Conclusion · Bridge.
Paragraph functions and relations: the lists in `lens-architecture.md` §A.2.

Target size: ≤ 40 lines for a section-length draft. If a draft exceeds ~1,500 tokens,
tag paragraph functions only and sample sentence roles for two representative paragraphs
(mirroring the extraction's own §A.3 policy), and record that the sampling was applied.

## 5. Reference side

Already tagged. Stage 2 workers read, per paper:

| need | source |
|------|--------|
| paragraph-function spine + relations + flow | `logic.md` §C |
| sentence-role chains + recurring chain shapes | `logic.md` §D |
| frame code distribution by section | `logic.md` §F |
| recurring Z shapes with counts | `logic.md` §F |
| Singleton/Recurrent status | `logic.md` §E.5, `anchors.txt` |
| lane discipline + hedge placement + zeros | `style-vocab.md` §C, §D |
| absences (Red Flags) | `card.md` |
| measured rows (sanity check only) | `manifest.json` |

`logic.md` is opened **only inside a Stage 2 worker** and never returned upward.

## 6. Comparison dimensions

Stage 2 emits one diff per reference paper. Exactly these eight dimensions, in this
order; each carries `MATCH` / `MISMATCH` / `n/a` and, for a mismatch, one concrete
observation.

| # | dimension | compared how |
|---|-----------|--------------|
| D1 | paragraph-function spine | draft sequence vs reference section spine |
| D2 | paragraph closers | what the last sentence of each paragraph does |
| D3 | sentence-role chains | draft chains vs reference recurring chain shapes |
| D4 | frame-code distribution | which families the draft over/under-uses for that section |
| D5 | gap type (I/D only) | which C-codes the reference uses and never uses |
| D6 | reporting-verb lanes | which verb governs literature / own inference / display items |
| D7 | hedge & qualification placement | sentence-initial modal vs clause-final rider |
| D8 | absences | Red-Flag hits (script-measured) |

**Artifact: `2-diff.<slug>.md`**, target ≤ 30 lines. Example (real, from the test draft):

```markdown
section: M   reference: kim-2015-nitrate-iso

D1 paragraph-function spine        MISMATCH
   draft:     [Procedure, Procedure, Claim]
   reference: 13 ¶; 2 of them close on a procedural DECISION
D2 paragraph closers               MISMATCH
   draft closes on: Method, Method, hedged Claim — no decision anywhere
D3 sentence-role chains            MISMATCH
   draft P2:      Method → Method
   reference P19: Method → Condition → Method → Method+Purpose → Decision+Qualification
   missing: Condition, Qualification
D4 frame-code distribution         MISMATCH
   draft E×2 F×1 Z×2   |   reference M: E×23 Z×19 A×4 F×2   → E under-used
D5 gap type                        n/a (Methods)
D6 reporting-verb lanes            MATCH
   draft `indicate` governs own inference — correct lane
D7 hedge placement                 MISMATCH
   draft: 0 clause-final riders | reference: 5 Assumption-Riders, all clause-final
D8 absences                        MISMATCH — 11 Red-Flag hits (see 1c-absence.tsv)
```

## 7. Pipeline

### 7.1 Artifact location

Next to the draft, never inside the corpus:

```
<draft-dir>/
├── my_methods.txt
└── run/<draft-stem>/
    ├── 0-draft.repr.md
    ├── 1a-structure.md
    ├── 1b-vocab.tsv
    ├── 1c-absence.tsv
    ├── 2-diff.<slug>.md          one per reference in scope
    ├── 3-prescriptions.md
    ├── 4-candidate.<id>.md       one per candidate
    ├── 4b-comparison.md
    └── 5-verify.tsv
```

### 7.1a Declared size bounds

Every artifact carries a bound so AC5 is checkable. A worker that would exceed its bound
must compress rather than overflow — it is a reduction step, and an overflowing reduction
defeats the context isolation the pipeline exists for.

| artifact | bound | on overflow |
|----------|-------|-------------|
| `0-draft.repr.md` | 60 lines | paragraph-level only; note the truncation |
| `0-draft.prose.txt` | unbounded (it is the input) | — |
| `profile_vocab.txt` | 60 lines | keep items the cards actually carry |
| `1a-structure.md` | 55 lines | sample sentence roles per §4; record that sampling applied |
| `1b-vocab.tsv` | 30 rows | keep items with a measured hit or a lane violation |
| `1c-absence.tsv` | 30 rows | keep hits only, never the zero rows |
| `2-diff.<slug>.md` | **90 lines** | compress prose; **never drop a dimension, an address or a quote** |
| `3-prescriptions.md` | 110 lines | merge prescriptions that share a fix; never drop a FIRM item |
| `4-candidate.<id>.md` | unbounded (it is the deliverable) | — |
| `4b-comparison.md` | 35 lines | table only; prose belongs in the report |
| `5-verify.tsv` | 12 rows | — |

Bounds were re-derived from a live run after four of nine artifacts overran the originals.
The `2-diff` case mattered most: the original 30-line bound, with an overflow rule that
kept "only the strongest observation per dimension", would have deleted the addresses and
role chains that made the diff usable. **A bound is a budget for prose, never a licence to
drop evidence.**

### 7.2 Stages

| stage | parallel | input | output | context cost |
|-------|----------|-------|--------|--------------|
| 0 segment | no | draft | `0-draft.repr.md` | draft only |
| 1a structure tag | **yes** | draft | `1a-structure.md` | draft only — no reference |
| 1b vocab measure | **yes** | draft + `card.md` §V | `1b-vocab.tsv` | script-driven |
| 1c absence check | **yes** | draft + `card.md` Red flags | `1c-absence.tsv` | script only |
| 2 compare | **yes, one per paper** | `1a` + that paper's `logic.md`/`style-vocab.md` | `2-diff.<slug>.md` | the only large read |
| 3 prescribe | no (barrier) | all `2-diff.*` + `1b` + `1c` | `3-prescriptions.md` | small files only |
| 4 generate | **yes, one per candidate** | draft + that candidate's prescription subset | `4-candidate.<id>.md` | no reference files |
| 4b compare & recommend | no (barrier) | all candidates | `4b-comparison.md` | small |
| 5 verify | no | recommended candidate | `5-verify.tsv` | script only |
| 6 report | no | `3`, `4b`, `5` | chat | small |

**Stage 1a must not see the reference.** Tagging the draft against a known target biases
the tags toward the target and manufactures a match. Tag blind, then compare.

**Stage 4 workers must not see the reference files.** By Stage 4 every reference finding
has been translated into a prescription; re-reading the source invites verbatim copying,
which the 216/220-Singleton finding forbids.

### 7.3 Parallelism

Stages 1a/1b/1c and Stage 2 and Stage 4 are dispatched as isolated workers when subagent
dispatch is available. When it is not, they run sequentially in the same order; the
context benefit is preserved because every stage reads and writes files rather than
holding sources in the conversation.

**Parallelism is not purely a speed property.** Worker separation is the mechanism that
enforces the two isolation rules in §7.2 — a worker never handed `logic.md` cannot read
it. Sequential execution reduces both rules to honor-system, and for Stage 1a a single
context that has already read the reference cannot honestly "tag blind". Sequential runs
must therefore tag the draft before opening any reference file, and must disclose in the
report header that isolation was by ordering rather than separation.

Never dispatch a worker without the user's go-ahead if the runtime requires it.

### 7.4 Re-entry

Each stage is a pure function of its declared inputs. Deleting `3-prescriptions.md` and
re-running rebuilds stages 3+ only. Adding a reference paper requires only that paper's
Stage 2 plus stages 3+. Changing the draft invalidates everything.

### 7.5 Failure and edge cases

| situation | behaviour |
|-----------|-----------|
| No corpus found | Ask for the path. Only if none exists, hand off to `metasci-style-extraction`. Never send a user who has cards back to extraction. |
| Corpus has no `style_profile.md` | Normal. Derive from cards; say so in one line. |
| `style_profile.md` older than a card in scope | Ignore, warn once, derive from cards. |
| **Draft section absent from the reference's scheme** | See §7.6 — this is the common case, not an error. |
| Draft <100 tokens | Skip Stage 1a sentence-role tagging and Stage 5 entirely. Run D6–D8 only (lanes, hedge placement, absences) and say the structural dimensions were not assessed. |
| `logic.md` missing from a paper folder (extraction incomplete) | That paper contributes D6–D8 only; record it in the report and reduce its weight in Stage 3, do not drop the paper silently. |
| A CHOICE item would reverse the draft's claim direction | Never apply. Flag as content-tension (retained claim-precedence rule, §11). |
| Corpus and draft languages differ | Stop. |
| No CHOICE mismatches found | Emit candidate A only, and say the draft already matches the reference structurally. Do not manufacture B and C. |

### 7.6 Section mapping

The reference's `manifest.prep.section_scheme` may not contain the draft's section. This
corpus is `IMRC` — Results and Discussion are fused — so a Discussion draft has no `D`
row.

Resolution, in order:

1. Exact match → use it.
2. **Fused-section match**: if `prep.detection_notes` records that the missing section is
   fused into another (e.g. "R and D appear fused"), use the fused section and **declare
   the substitution in the report header**. This is legitimate: the reference's `R`
   genuinely contains discussion prose.
3. No match and no fusion note → do not substitute another section's band or spine.
   Report which sections the corpus covers and run D6–D8 only.

Rule 2 is the only permitted cross-section substitution, and only on the evidence already
recorded by `prep.py`. Never infer fusion from the section's content.

## 8. Candidates

### 8.1 Axis selection

Prescriptions are partitioned in Stage 3 into three classes; only the third varies
between candidates.

| class | varies? | source |
|-------|---------|--------|
| **FIRM** — absences / Red Flags | no — in every candidate | `card.md`, D8 |
| **BAND** — numeric sanity targets | no — same for all | `manifest.json`, §9 |
| **CHOICE** — structural and stance habits | **yes — this is the axis** | D1–D3, D7 |

At N≥3, a second axis appears: any dimension classified `divergence` (per the v3.0
spread rule, retained) splits a candidate into a low-lean and a high-lean variant.

### 8.2 Candidate set

Maximum **3**. More candidates transfer the decision back to the user instead of helping.

| id | contents | intent |
|----|----------|--------|
| **A** conservative | FIRM + BAND only | preserve the author's own voice; minimum intervention |
| **B** standard | A + the CHOICE items natural to that section | adopt the reference's signature moves |
| **C** deep | B + sentence-role chain rearrangement per D3 | restructure the paragraph's internal logic |

`Light` / `Standard` / `Deep` from v3.0 are replaced by A/B/C. The improvement is that
intensity is now defined by **which diagnosed items were applied** — auditable — rather
than by an adjective.

If a candidate's defining items are empty (e.g. no CHOICE mismatches at all), emit fewer
candidates and say why. Never pad to three.

### 8.3 Presentation

Order fixed:

1. **Comparison table** — one row per candidate: which prescription IDs it applied, plus
   its measured row.
2. **Recommended candidate in full**, with a one-paragraph reason tied to a specific
   diagnosis line (not "it reads better").
3. **The others as differences from the recommended** — only the sentences that differ.
   Never reprint a full paragraph three times.

### 8.4 Singleton constraint

A frame marked `Singleton` in `anchors.txt` may appear at most once in any candidate, as
its author used it. When the Singleton/Recurrent status was not loaded, fall back to the
card's aggregate ratio and **state that the fallback was used**.

---

### 8.5 Content-preservation gate

Runs in Stage 4b **before** any candidate comparison.

A prescription of the form "remove X" or "replace X with Y" can be satisfied by deleting
the sentence containing X. The Red-Flag count cannot catch this — the flag is absent
either way. Measured on the test draft: `F1 "Figure 2" → "Fig. 2"` produced a candidate
with **no figure reference at all**, reading as 0 Red-Flag hits and otherwise clean.

Compare draft vs candidate on three multisets — display-item references
(`Fig.|Figure|Table|Eq.` + number), citation keys, and numerals:

| result | action |
|--------|--------|
| count preserved, form changed | correct — the prescription was applied |
| count reduced | **disqualify the candidate**; regenerate with the item restored |
| numeral changed | **stop** — a data value was altered, never permitted |

## 9. Numbers, demoted

Numbers no longer drive prescription. They serve one purpose: catching a revision that
drifted implausibly far from the reference's register.

- Bands are derived exactly as in v3.0 §Band Derivation (N-tier + length widening,
  effective band computed once in Stage 3).
- Stage 5 reports each candidate's row against the band.
- **Out of band is a warning, not a failure**, and it never triggers an automatic rewrite.
  It is surfaced in the report for the author.
- The report must state, verbatim: *"Numbers are a sanity check, not the target."*
- **Prohibited**: a prescription whose only justification is a metric gap. Every
  prescription cites a D1–D8 dimension or an absence.

This restores consistency with `metasci-style-extraction`'s rule 2.

---

## 10. Tier gating (retained from v3.0)

Unchanged and still correct:

| N | tier | FIRM | CHOICE |
|---|------|------|--------|
| 1 | `single-source` | absences only | every structural habit is a candidate axis, never imposed on all candidates |
| 2 | `provisional` | absences confirmed 0/2 | labelled provisional |
| ≥3 | `corpus` | convergent items with count | divergence splits candidates |

Report header declares tier, N, and slugs. Section C of the report ("what was deliberately
not imposed") is never empty.

## 12. Acceptance criteria

Verified against the recorded v3.0 baseline (§1.2), same draft, same corpus.

- **AC1** Stage 2 names ≥3 concrete structural mismatches on the test draft. *(v3.0: 0)*
- **AC2** Every candidate has 0 Red-Flag hits, script-measured.
- **AC3** The recommended candidate contains, verifiably by anchor count, ≥2 of the
  CHOICE moves it claims to apply. *(v3.0: 0 of 5)*
- **AC4** No **FIRM or CHOICE** prescription cites a metric gap as its sole justification;
  each names a D1–D8 dimension or a card absence. (BAND items are metric by definition and
  are exempt — they are sanity targets, not prescriptions.)
- **AC8** Every candidate passes the content-preservation gate (§8.5): display-item
  references, citation keys, and numerals are preserved or transformed, never reduced. A
  candidate failing the gate is not offered, regardless of its other measures.
- **AC5** Every `run/` artifact stays within its declared bound (§7.1a); the main
  conversation never holds `logic.md`, `style-vocab.md`, or `wordlist.tsv`.
- **AC6** Deleting `3-prescriptions.md` and re-running rebuilds stages 3+ only, producing
  byte-identical stage 0–2 artifacts.
- **AC7** With N=1, the report's "not imposed" section lists every CHOICE item that
  candidate A omitted.

## 13. Risks

| risk | mitigation |
|------|------------|
| Draft tagging is LLM judgment; "the measurement wins" weakens | The comparison target is a fixed, human-inspectable artifact (`logic.md`), not a vibe. Tag blind (§7.2). Record tags in `1a-structure.md` so a human can dispute them. |
| Cost per run rises (N+4 workers vs 1 pass) | Stage 1a/1c are cheap; Stage 2 is the only large read and is bounded by N. Short drafts may skip Stage 1a sentence-role tagging (§4). |
| Overlap with `meta-review` | NG1 draws the line: structure-match vs argument-soundness. The report's "optional next steps" points to `meta-review` rather than doing it. |
| Three candidates read as indecision | §8.3 requires a recommendation with a reason, and §8.2 forbids padding to three. |
| Structural prescriptions could alter meaning | §NG5 plus the retained claim-precedence rule: strength is style, direction is content; a direction reversal is flagged, never applied. |

## 14. Out of scope for this spec

- **Korean drafts — dropped entirely from v4.0.** The frame taxonomy (A1–L4 + Z), the
  paragraph-function tags, and the sentence-role list are all derived from English
  academic prose; applying them to Korean would produce tags that look authoritative and
  mean nothing. v4.0 therefore **does not accept Korean drafts or Korean corpora**: it
  detects the language via `quant_check.py` and stops with a pointer to
  `meta-mywriting-korean` (personal Korean voice) or `meta-report-writing` (Korean
  institutional register). The v3.0 experimental Korean path is removed rather than
  carried forward — a half-working path that labels itself experimental still gets used.
  Korean support would need its own representation taxonomy and is a separate project.
- Automatic `style_profile.md` generation. Still `aggregate.md`'s job, still optional.

some has never run. The difference matters when a finding looks surprising.

| **AC2** 0 Red-Flag hits in every candidate | script-measured on A/B/C |

### Not verified

| what | why it matters |
|------|----------------|
| **AC6** re-entry | never exercised — no stage file was deleted and re-run. If broken, a "regenerate candidate B" request re-does the whole diagnosis. Wasteful, not dangerous. |
| **AC7** report §E | the format is specified but **no §E was ever produced** — the test run stopped at Stage 5. §E is what carries the report's honesty at low N. |
| **parallel dispatch** | never run. All stages executed sequentially in one context. |
| **Stage 1a blind tagging** | **violated during the test.** The tagger already knew the reference paper's structure. See the caveat below. |
| **§7.6 section mapping** (fused R+D) | never triggered — the test draft was Methods, which both papers have. A Discussion draft would exercise it. |
| **fresh-context execution** | the guide's author also executed it. Ambiguities in the instructions were filled from intent, not from the text. |
| **a real user draft** | the test draft was synthetic, 112 tokens, built to contain 12 planted violations. |

### The caveat that qualifies AC1 and AC3

Stage 1a's isolation rule — *tag the draft without reading the reference* — **was not kept
during the test run**, because the same context had already read `logic.md` in full.
Tagging under that condition pulls tags toward the target, which is exactly the bias the
rule exists to prevent.

So **AC1 (7 mismatches) and AC3 (3 CHOICE moves carried) should be read as upper bounds,
not as replicated results.** They remain a large improvement over the v3.0 baseline of 0
and 0 — that comparison holds, because the baseline was produced the same way — but the
absolute numbers may not survive a run where Stage 1a is genuinely blind.

The cheapest way to settle it: run Stage 1a as a separate worker that is handed the draft
and nothing else.

## 16. Live-run findings, 2026-08-17

First execution against a real manuscript (`Result_discussion.md`, a fused Results-and-
Discussion draft) by an agent that had not written the skill, on the two-card `SCI_kkh`
corpus.

### What held

- N and tier announced correctly (`provisional`, N=2, both slugs).
- The report cited section-specific figures the card alone does not carry (Z rate 38.6%
  for the 2015 paper's R section, not the card's whole-paper 39.5%) — evidence that
  `logic.md` was genuinely read, which is the whole point of v4.0.
- Candidate A came out **empty** — 0 FIRM prescriptions — and the run reported that as a
  result rather than manufacturing edits. The no-padding rule worked.
- §E was produced for the first time, 11 rows, and correctly demoted the four Red Flags
  that fail the N=2 gate.
- Isolation-by-ordering was performed *and disclosed*, in both the report and
  `1a-structure.md`.

### Six defects found

| # | defect | fixed in |
