# Content Analysis

Use this reference before planning slides from a paper, report, policy document, proposal, long notes, or dense existing deck. The goal is source-faithful structure, not creative summarization.

## Procedure

1. Read the source material closely.
2. Identify the core topic, major claims, definitions, assumptions, methods, evidence, results, limitations, and conclusions.
3. Separate source claims from your own inferred implications. Label inferences explicitly.
4. If the source is insufficient or ambiguous, ask for the missing material or mark an open question.
5. Group content into logical blocks: background, problem, concept, method, evidence, result, implication, and next step.
6. When a report section must become slide content, structure the section as a concise topic plus complete analytical bullets before drafting slide text.

## Source Map

Produce a compact map before slide planning:

```text
Core Topic:
Central Claim:
Audience Need:

Key Claims:
- Claim:
  Evidence:
  Source Location:
  Confidence:

Definitions:
- Term:
  Meaning in source:
  Why it matters:

Methods or Process:
- Step:
  Input:
  Output:
  Evidence:

Implications:
- Source-supported implication:
- Inference that needs confirmation:

Open Questions:
- Question:
  Why it matters:
```

## Compression Rules

- Preserve causal logic, definitions, assumptions, and method differences.
- Do not reduce a technical argument to a slogan.
- Keep 3-6 core claims per major section before converting to slides.
- If one section contains multiple argument lines, split it into multiple slide candidates.
- Prefer objective analytical Korean for Korean decks.
- For Korean section bullets, use complete explanatory sentences rather than keyword fragments.
- Keep the bullet sequence logical: general -> specific, context -> feature, cause -> result, or method -> implication.
- Do not add claims, examples, numbers, citations, or implications beyond the provided source.

## Section Structuring Output

Use this shape when the user asks to analyze a report section, or when dense source sections must be compressed before slide planning:

```text
주제: [간결한 제목]

• [핵심 내용 1: 1-3문장의 완성된 설명]
• [핵심 내용 2: 1-3문장의 완성된 설명]
• [핵심 내용 3: 1-3문장의 완성된 설명]
```

Rules:

- Write 3-6 bullets per section.
- Choose a short title that reflects the section's central topic.
- Use concise objective analytical endings such as `-함`, `-됨`, `-나타남`, `-해석됨`, `-필요함`, `-어려움`, `-유용함`, or `-적절함`.
- Use `-고 있음` only when an ongoing process or current state must be emphasized; avoid repeating `있음` across bullets.
- Prefer compressed forms such as `필요함`, `요구됨`, or `검토해야 함` instead of longer forms such as `필요가 있음`.
- Avoid visible planning labels such as `Background:`, `Evidence:`, and `Implication:` unless the user asks for the planning scaffold.
- Preserve only source-supported content; mark unclear points as open questions.

## Title Extraction

For each section, extract:

```text
Keyword Title:
Lead Statement Candidate:
Supporting Blocks:
Evidence Candidate:
Transition Need:
```

The keyword title should be a noun phrase. The lead statement candidate should be a complete sentence that can become the slide's point.
