# Gap Statement Templates

Pattern collection for Knowledge Gap statements. Reference during Stage 2 Generation as needed.

## Type 1: Multi-dimensional Gap
```
However, three critical gaps remain:
(1) [empirical gap],
(2) [methodological gap], and
(3) [theoretical gap].
```

## Type 2: Scale Mismatch
```
While local-scale studies demonstrate [finding],
[system]-level responses remain poorly characterized,
limiting our ability to [prediction/management need].
```

## Type 3: Mechanistic Gap
```
Despite extensive documentation of [pattern],
the underlying mechanisms driving [process] remain elusive,
precluding robust predictions under [changing conditions].
```

## Type 4: Methodological Limitation
```
Previous approaches have been constrained by [limitation],
preventing comprehensive assessment of [target].
Recent advances in [method] now offer the opportunity to [capability].
```

## Type 5: Temporal Gap
```
Although short-term studies (<[N] years) reveal [trend],
long-term trajectories of [process] under [driver] remain unknown,
creating uncertainty in [projections/management].
```

## Type 6: Geographic/System Gap
```
The majority of evidence derives from [well-studied system/region],
whereas [understudied system/region] — which accounts for [proportion] of [global metric] —
remains largely uncharacterized.
```

## Type 7: Contradiction/Debate
```
Conflicting evidence exists regarding [topic]:
while [studies A] suggest [finding X],
[studies B] report [finding Y],
highlighting the need for [resolution approach].
```

## Type 8: Integration Gap
```
Although [process A] and [process B] have been studied independently,
their interactive effects on [outcome] are poorly understood,
despite growing recognition that [integrative importance].
```

## Transition Signals for Gap Introduction
- However, despite these advances, ...
- Nevertheless, critical knowledge gaps persist.
- Yet, our understanding of ... remains incomplete.
- Notwithstanding these contributions, ...
- A fundamental limitation of existing work is ...
