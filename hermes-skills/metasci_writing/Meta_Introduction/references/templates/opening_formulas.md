# Opening Sentence Formulas

Patterns for Introduction P1 opening sentences. Reference during Stage 2 Generation as needed.

## 1. Statistical Hook
```
[Phenomenon] affects [quantitative scope], with [consequence]
contributing to [broader impact] (Author et al., Year).
```

## 2. Paradox / Contradiction
```
While [conventional understanding/expectation],
recent evidence reveals [surprising finding],
challenging established paradigms of [domain] (Author et al., Year).
```

## 3. Urgency / Crisis Frame
```
The accelerating [phenomenon] threatens [target/system],
requiring urgent scientific understanding of [mechanism/process]
to inform [policy/management response].
```

## 4. Knowledge Evolution
```
Traditional understanding of [topic] has been fundamentally reshaped
by [discovery/technological advance],
revealing [new dimension] of [system] (Author et al., Year).
```

## 5. Quantitative Trend
```
Over the past [timeframe], [metric] has [changed by amount],
reflecting [underlying driver] with profound implications
for [affected system/society] (Author et al., Year).
```

## 6. Scale Statement
```
[System], covering [area/proportion] of [Earth's surface/global total],
plays a critical role in [function/process],
yet remains among the least understood [components] of [larger system].
```

## 7. Societal Relevance
```
With [population/economic metric] depending on [resource/service],
understanding [process] is essential for [practical goal],
particularly under [projected change scenario].
```
