# 출력 규약

> **내용 계약이지 렌더링 규칙이 아니다.** 시각적 배치는 표준 마크다운 범위에서
> 재량이되, 아래에 정한 것은 반드시 있어야 한다. 상자를 손으로 그리거나
> 수평선을 남발하지 않는다.

---

## 1. 절대 규칙 — 층 표기

**모든 지적에 층 표기가 붙는다.** 표기 없는 지적은 출력하지 않는다.

```
[L1 · 확정]   규칙 위반. 교정형 + 출처·쪽수
[L2 · 확정]   리뷰어 과반 지적. 준거명 + 배점 + k/n
[L2 · 소수]   1인 지적. 확정 아님
[L3 · 선택]   후보 N개. 최적 없음. 저자 결정
[L3 · 충돌]   Blueprint(기술적) vs 매뉴얼(처방적). 판정 안 함
[판정 불가]   모드 제약 또는 근거 부족
```

층을 섞어 한 목록으로 늘어놓지 않는다. **L1 → L2 → L3 순으로 절을 나눈다.**
신뢰도가 다른 것을 같은 형식으로 내놓으면 사용자가 구별할 수 없다.

---

## 2. L3에 금지된 표현

**최적안 · 추천 · 권장 · 개선안 · 더 낫다 · 자연스럽다 · 매끄럽다 · ~해야 한다**

"자연스럽다"·"매끄럽다"가 금지어인 이유: 그것이 바로 QWK .43~.48로 측정된
판단이며 근거를 대지 못하는 인상 진술이기 때문이다.

**허용**: 후보 · 선택지 · 트레이드오프 · ~을 얻고 ~을 잃는다 · 저자 판단

---

## 3. 출력 구성

```markdown
## 요약
{층별 건수: L1 확정 n건 / L2 확정 n건·소수 n건 / L3 선택 n건 / 판정 불가 n건}
{가장 중요한 것 2~3건을 산문으로}

## L1 — 규칙 위반 (확정)
{항목들}

## L2 — 논증 준거 (패널 판정)
{확정 → 소수 → 판정 불가 순}

## L3 — 문체·응집성 (저자 결정)
{항목들. 각 항목에 원문이 맨 위}

## 판정 불가
{모드 제약으로 볼 수 없었던 것. "통과"가 아니라 "못 봤음"임을 명시}

---
{범위 고지}
```

### 요약 절의 규칙

건수만 늘어놓지 않는다. **가장 중요한 2~3건은 산문으로 쓴다** — 무엇이 문제이고
왜 그것이 먼저인지. 나머지는 아래 절에서 목록으로 본다.

---

## 4. 항목 형식

### L1

```
[L1 · 확정] R{n} {규칙명}   ({위치})
  원문: "…"
  교정: "…"
  근거: {출처 약칭} {쪽수}
```

동일 유형이 반복되면 **1건으로 묶고 나머지 위치만 나열**한다(국립국어원 2024
채점 운영 규칙). "R4 관형격 '의' 남용 — P3-S1 외 4곳" 형태.

### L2

```
[L2 · 확정] {준거번호} {준거명} (배점 {n}, 리뷰어 {k}/{n} 지적)
  판정 근거: "{원문 인용}"
  출처: {약칭} {쪽수}
  보완 방향: {무엇을 채워야 하는가 — 문장을 대신 쓰지 않는다}
```

### L3

```
[L3 · 선택] {항목}   ({위치})
  ① 원문: "…"
     그대로 두면: {…}
  ② 후보 A: "…"
     얻는 것 {…} / 잃는 것 {…}
  ③ 후보 B: "…"
     얻는 것 {…} / 잃는 것 {…}
  근거: {출처} | "출처 없음 — 제안일 뿐"
  ※ 이 층은 판정하지 않습니다. 셋 중 저자가 고릅니다.
```

**원문이 항상 ①이다.** 아무것도 하지 않는 선택지가 기본값이라는 뜻이다.

---

## 5. 판정 불가를 숨기지 않는다

Mode 3(단락)에서 섹션 간 정합은 판정할 수 없다. 이것을 **출력에서 빼지 않는다.**

```
## 판정 불가
- L2 섹션 간 정합 (질문 사슬, Abstract↔본문, 명제 일관성)
  단락 하나만 보고 있어 판정 불가. 서론·결론까지 함께 봐야 합니다.
```

빼면 사용자는 통과했다고 읽는다.

---

## 6. 고정 삽입 — 범위 고지

출력 말미에 반드시 넣는다.

```
━━━ 범위 고지 ━━━
이 결과는 층별로 신뢰도가 다릅니다. L1은 명문 규칙 대조, L2는 리뷰어 합의,
L3는 선택지 제시입니다. L3에 최적안이 없는 것은 누락이 아니라 설계입니다 —
문장 연결성·어휘 적절성은 인간 평정자 간 일치도가 QWK .48·.43 수준이며
(Kim 2026), 그 층위에서 단일 정답을 제시하는 것은 측정 가능한 근거를
넘어섭니다.

인용·수치의 진위는 검증하지 않았습니다. 주장 단위 검토는 저자의 몫입니다.
리뷰어와 판정자는 같은 모델이며, 이들의 일치는 정확성이 아니라 현저성을
측정합니다.
```

---

## 7. 자기보고임을 밝힌다

리뷰어·판정자가 스스로 점검한 결과다. **"검증 통과"를 품질 보증으로 제시하지
않는다.** 각 판정이 무엇과 대조되었는지(출처 약칭·쪽수)를 밝히고, 추상적으로
품질을 주장하지 않는다.

중요한 문서라면 심의에 참여하지 않은 별도 검증자를 두는 것이 낫다.
