# L1 — 문장 규칙 (결정적 판정)

> **판정 방식**: 결정적. 리뷰어 합의 불필요. 검출되면 지적하고 교정형을 제시한다.
> **근거**: Kim(2026) Level 1 규칙 기반 평균 QWK **.915**
> **필수**: 지적할 때마다 아래 표의 `근거` 열을 함께 표시한다. 출처 없는 지적 금지.

출처 약칭 — `법제처` = 『알기 쉬운 법령 정비기준』 / `바로쓰기` = 국립국어원
『한눈에 알아보는 공공언어 바로 쓰기(개정판)』(2022/24) / `길잡이` = 국립국어원
『쉬운 공문서 쓰기 길잡이』(2022) / `지침2021` = 국립국어원 『행정문서 표현 개선 및
쉬운 공공언어 쓰기 지침 개발』(2021, 정희창)

## A. 번역투 — 일본어 투

법제처 제2장 §4(40–56쪽)가 가장 완성도 높은 목록이다. 그대로 규칙화한다.

### R1. `~에 있어(서)` / `~에 있어서의`

일본어 `~において / ~における` 직역.

| 검출 | 교정형 |
|---|---|
| 승진**에 있어서** 차별해서는 | 승진**에서** |
| 도급계약**에 있어서** | 도급계약**의 경우** / 도급계약을 **할 때** |
| 적용함**에 있어서** | 적용**하는 경우** / 적용**할 때** / 적용**하여** |
| 제공함**에 있어** | 제공**하는 데(에)** |
| 위기**에 있어서** | **위기로** / **위기가 발생하여** |
| 이번 선거**에 있어서** | 이번 선거**에서** |

**근거**: 법제처 §4 / 바로쓰기 p.11

### R2. `~에 의하여 ~되다`

일본어 `依って` + 영어 수동태 직역. **행위 주체를 주어로 한 능동문**으로 바꾼다.

| 검출 | 교정형 |
|---|---|
| 일반 소비자**에 의하여** 일상 **사용되는** 것 | 일반 소비자**가** 일상적으로 **사용하는** 것 |
| 국민**에 의하여 실시된** 조사 | 국민**이 실시한** 조사 |
| 학교법인**으로부터 제출된** 신청서 | 학교법인**이 제출한** 신청서 |
| 조선은 태조 이성계**에 의해 건국되었다** | 조선은 태조 이성계**가 건국했다** |
| 공무원 채용은 공개경쟁시험**에 의한다** | 공무원은 공개경쟁 채용시험**으로 채용한다** |

**예외**: 법제처는 **주어가 무생물인 경우 피동문을 허용**한다.
**근거**: 법제처 §5(126–129쪽) / 바로쓰기 p.11 / 김순영(2012)

### R3. `~으로부터`

| 검출 | 교정형 |
|---|---|
| 그 사람**으로부터** 들은 | 그 사람**에게서** |
| 긴장**으로부터의** 해방 | 긴장**에서 벗어나는** |
| 한강**으로부터** 10km | 한강**에서** 10km |

**근거**: 김순영(2012) 『새국어생활』 22(1)

### R4. 관형격 `의` 남용

일본어 `の` 영향. **자리별로 교정형이 다르다.**

| 자리 | 검출 | 교정형 |
|---|---|---|
| 주격 | 저작자**의** 생존하는 동안 | 저작자**가** 생존해 있는 동안 |
| 주격 | 혼인관계**의** 종료한 때 | 혼인관계**가** 종료된 때 |
| 목적격 | 급여**의** 지급을 위하여 | 급여**를 지급하기** 위하여 |
| 목적격 | 「국가보안법」**의** 위반행위로 | 「국가보안법」**을 위반하여** |
| 서술어 | 두께가 4.5mm 이상**의** 것 | 두께가 4.5mm 이상**인** 것 |
| 서술어 | 18세 미만**의** 자 | 18세 미만**인 사람** |
| 중첩 | 우리**의** 인생**의** 깊이 | 우리 인생**의** 깊이 (앞 '의' 생략) |

**근거**: 법제처 §4 / 정언학(2014) p.118

### R5. 명사 나열형 (명사구 남용)

**법제처가 명시적으로 금지한다.** 조사·보조사를 넣거나 명사를 동사·형용사로 바꾼다.

| 검출 | 교정형 |
|---|---|
| 부품의 호환성 제고를 위하여 | 부품의 호환성을 **높이기** 위하여 |
| 집행유예선고를 받고 | 집행유예**를 선고받고** |
| 피난장소 도착시의 조치 | 피난 장소에 **도착했을 때의** 조치 |
| 부대정문초소경계근무 | 부대 정문 초소**의** 경계 근무 |

**한자어 3개 이상 단순 나열** 시 '-의'를 추가하거나 서술어를 보충한다(정언학 2014 p.120).

**예외**: 법제처 명문 — "명사 나열형 문장이더라도 문장이 어색하거나 어렵지 않으면
장황하게 풀어쓰지 않고 그대로 둔다."

**근거**: 법제처 §4 / 길잡이 p.49 / 정언학(2014) p.120 / 김미선·이지용(2018)

### R6. 기타 일본어 투 정형

| 검출 | 교정형 | 근거 |
|---|---|---|
| ~을 **요하는** / **요하지 아니한다** | ~이 **필요한** / **필요하지 않다** | 법제처 |
| 특별한 사유가 없는 **한** | 특별한 사유가 **없으면** | 법제처 |
| ~에 **한하여** / **한한다** | ~에**만** / ~에 **한정한다** | 법제처 |
| 1회**에 한하여** | **한 차례만** | 법제처 |
| 우리의 목표는 통일**에 있다** | 우리 목표는 통일**이다** | 바로쓰기 p.12 |
| 이 법**에** 규정한 | 이 법**에서** 규정한 | 법제처 |
| 반하지 아니하는 **한** | 반하지 아니하는 **범위에서** | 법제처 |

### R7. 조사 `에` 오용 (일본어 `に` 직역)

| 검출 | 교정형 |
|---|---|
| 보험**에** 관계있는 | 보험**과** 관계있는 |
| 기산일**에** 소급하여 | 기산일**로** 소급하여 |
| 운송용**에** 제공하거나 | 운송용**으로** 제공하거나 |
| 원상**에** 회복하여야 | **원상태로 돌려 놓아야** |
| 결원 수**에** 부족하고 | 결원**보다** 적고 |
| 소유자**에** 속한 경우 | 소유자**에게** 속했을 때 |

**근거**: 법제처 §4

## B. 번역투 — 영어 투

일본어 투와 달리 **단일 완성 목록이 없다.** 김순영(2012)의 3분류와 김정우(2012)의
코퍼스 대조를 결합해 구성했다.

### R8. `have` → `가지다` 대응

| 검출 | 교정형 |
|---|---|
| 처자를 **가진** 가장 | 처자가 **있는** 가장 |
| 책을 옆구리에 **가지고 있다** | 책을 옆구리에 **끼고 있다** |
| 아름다운 목소리를 **가지고 있다** | **목소리가 아름답다** |

**근거**: 김순영(2012)

### R9. 복수 `-들` 삽입

한국어 '-들'은 단순 복수 표지가 아니라 **'여러 종류의 다양한'이라는 느낌**을
전달한다. 영어 `-s`를 기계적으로 옮기면 의미가 어긋난다.

| 검출 | 교정형 |
|---|---|
| 새로운 **아이디어들과 방법들** | **여러 가지 남다른 생각과 방법** |
| 많은 학생**들**이 있다 | 많은 학생이 있다 |

**근거**: 김순영(2012)

### R10. 무생물 주어 능동 구문

| 검출 | 교정형 |
|---|---|
| **이 설문조사 결과는** ~해야 한다는 점을 **말해 주고 있다** | ~해야 한다는 점을 **이 설문조사 결과에서 알 수 있다** |

**근거**: 바로쓰기 p.11

### R11. 코퍼스 대조로 확인된 번역문 과다 항목

김혜영(2009) 100만 어절 × 2 균형 말뭉치 대조. **검출 시 즉시 오류가 아니라
과다 사용 여부를 본다.**

| 층위 | 번역문에 과다 |
|---|---|
| 체언 | 2·3인칭 대명사(그·이것·그것), 의존명사 '것/거', '때문' |
| 용언 | 만들다·가지다·의하다·대하다, 통사적 피동 `-아/어 지다` |
| 부사 | 정도부사 가장·매우·아주·너무 |
| 접속부사 | 그리고·그러나·하지만·왜냐하면 |
| 조사 | 관형격 '의', 부사격 '-에게서·-으로부터·-으로', 주제 '-은/는' |
| 구문 | `-에 의하여` 피동, 장형 사동 `-게 하다/-게 만들다`, `-수 없다` |

**근거**: 김정우(2012) 『새국어생활』 22(1), 김혜영(2009) 재인용

## C. 피동

### R12. 피동 중첩 (이중피동)

**판정 규칙 — 다음 3장치 중 2개 이상이 겹치면 검출.**
① 피동 접미사 `-이/히/리/기-` ② `-어지다` ③ `-게 되다`

| 검출 | 교정형 | 확인 수준 |
|---|---|---|
| 보여지다 / 보여진다 | 보이다 / 보인다 | 국립국어원 온라인가나다 |
| 되어지다 (생각되어진다) | 되다 (생각된다) | 국립국어원 |
| 먹어지게 되다 / 먹게 되어지다 | 피동 장치 하나만 | 국립국어원 |
| 발견되어진다 | 발견된다 | 정언학(2014) p.146 |

> ⚠ **과잉 규범 주의.** 어문 규범에 이중피동 조항이 없고 국립국어원 답변도
> "부자연스러울 가능성이 높다"는 완화된 표현을 쓴다. 학계에 기능 인정론도 있다.
> **`쓰여지다·읽혀지다·놓여지다·잊혀지다·불리우다`는 1차 출처를 확보하지 못했다.**
> 위 4건만 출처를 붙여 지적하고, 나머지는 지적하지 않거나 출처 없이 제안만 한다.

**판별 보조**: 어기가 이미 피동사인가? '보이다'는 '보다'의 피동사이므로 `-어지다`
결합이 중첩이다. '느끼다·남다'는 피동사가 아니므로 '느껴지다·남겨지다'는 정상이다.

### R13. 자동사에 피동 형태

| 검출 | 교정형 |
|---|---|
| **발생된** 광해의 방지 | **발생한** 광해의 방지 |

**근거**: 법제처 §5 — "'발생하다'는 그 자체로 자동사이므로 피동 형태로 쓸 수 없다."

### R14. 격조사–태 불일치

| 검출 | 교정형 |
|---|---|
| 국회의원 ○○명**을 선출되었다** | ○○명**을 선출하였다** / ○○명**이 선출되었다** |

**근거**: 바로쓰기 p.11 — 지침의 초점은 "피동 금지"가 아니라 **격조사와 태의 불일치**다.

## D. 문장 성분 호응

이론 틀은 **서술어 자릿수**다(이관규 2005). "서술어에 호응하는 문장 성분은
통사적 조건과 의미적 조건이 모두 맞아야 한다."

- 한 자리: 불다, 예쁘다 → 주어만
- 두 자리: 먹다(주어+목적어), 되다(주어+보어 또는 주어+필수 부사어)
- 세 자리: 주다, 삼다, 여기다 (주어+목적어+필수 부사어)

### R15. 필수 성분 누락

| 검출 | 교정형 |
|---|---|
| 자신의 방법으로 **풀어가는** 모습 | 자신의 방법으로 **[문제를] 풀어 가는** 모습 |
| 저는 **다르게** 생각합니다 | 저는 **[그것과] 다르게** 생각합니다 |
| 사람**이** 몇이나 죽였어? | 사람**을** 몇이나 죽였어? |
| 막혔던 무엇**을** 풀려 내리는 | 막혔던 무엇**이** 풀려 내리는 |

**근거**: 이관규(2005) 『새국어생활』 15(4)

### R16. 하나의 주어에 두 서술어 — 뒤 서술어 불호응

| 검출 | 교정형 |
|---|---|
| **이번 조사는** …설계되었으며 …**자료로 사용될 것입니다** | 이번 조사는 …설계되었으며 **[그 조사 결과는]** …사용될 것입니다 |

**근거**: 이관규(2005) / 법제처 §3-3 "하나의 주어에 하나의 서술어를 쓴다"

### R17. 접속 병렬성

`-고`, `-며`, `-와`, `-과`, `또는`, `및`으로 접속되는 항은 **구조가 같아야** 한다.

| 검출 | 교정형 |
|---|---|
| 평화 **수호와** 인권**을 보장하는** 것 | 평화**를 수호하고** 인권을 보장하는 것 / 평화 **수호와** 인권 **보장** |
| **필요 또는 유익한** 채무 | **필요하거나 유익한** 채무 |
| **선의, 평온 및 공연하게** 점유한 | **선의로, 평온하고 공공연하게** 점유한 |
| 기업인**의** 사기진작과 경영 **의욕을** 고취시키고 | 기업인의 **사기를 북돋우고** 경영 의욕을 **고취하여** |

**근거**: 바로쓰기 / 법제처 §6 / 길잡이 p.18

### R18. 조사·어미 과잉 생략

| 검출 | 교정형 |
|---|---|
| 종합 계획을 **수립**, 올 하반기부터 시행 | 종합 **계획을 수립하여**, 올 하반기부터 시행 |
| 버스**로** 개조**으로** 예산 절감 | 버스로 개조**함으로써** 예산 절감 |
| '애드 온' 개념 **도입하여** | '애드 온' **개념을 도입하여** |

**근거**: 바로쓰기 p.12 / 길잡이 p.18

### R19. 수식어–피수식어, 주어–서술어 이격

| 검출 | 교정형 |
|---|---|
| **「국민이」** 제9조에 따른 …정보**에 쉽게 접근할 수 있도록** | …정보에 **「국민이」 쉽게 접근할 수 있도록** |

**근거**: 법제처 §3-4

## E. 간결성

### R20. 의미 중복

| 검출 | 교정형 |
|---|---|
| 도립공원위원회**의 구성은** …**구성한다** | 도립공원위원회**는** …**구성한다** |
| 심사평가를 **실시할** 수 있다 | 심사평가를 **할** 수 있다 |

**근거**: 법제처 §8-1 — 하위 규칙: 가) 중복 표현 생략 나) 당연한 내용 생략
다) 불필요한 내용 생략

### R21. 한 문장 = 1개 정보

> "**한 문장에 2개 이상의 정보를 담고 있으면 의미 파악이 어려워진다.**"

정보가 여럿이면 문장을 나눈다. 실례(바로쓰기 p.11): 100자 1문장 → 3문장 분할.

**근거**: 지침2021 부록7 p.93 / 바로쓰기 p.11 / 길잡이 p.17

### R22. 조·항 = 최대 2문장 — **법령문 구간에만 적용**

> "일반적으로 조나 항은 한 문장으로 구성한다. … **세 문장 이상으로 규정하거나
> 단서와 후단을 같이 규정하면 지나치게 복잡하므로** 그 내용을 적절히 나눈다."

**근거**: 법제처 §2-5(109–110쪽)

> ⛔ **적용 범위 제한 (2026-08-04 수정).** 이 규범의 대상은 **법령의 조·항**이지
> 산문 문단이 아니다. 초판에서 "한 논지 단위"로 일반화해 적은 것은 오류였다.
> 그대로 두면 `L1_paragraph_rules.md` P1(한 문단 5~8문장)과 정면 충돌한다 —
> 5문장 문단이 P1은 충족하면서 R22는 위반하게 된다.
>
> **적용 대상**: 원고에 인용·제시된 법령 조문, 조례, 규정 본문.
> **적용 제외**: 일반 산문 문단. 문단의 문장 수는 **P1만** 적용한다.

> ⚠ **"한 문장 N어절 이내"는 쓰지 않는다.** 어절 단위 권장 상한을 제시한
> 한국어 실증 연구를 확인하지 못했다. 참고 실측치만 있다 — 한국 신문 평균
> 문장 길이 **60.1자**(일본 47.2자), 문장당 쉼표 **0.36개**(일본 1.49개),
> 김한식(2010: 72). 이것은 기준이 아니라 분포다.
