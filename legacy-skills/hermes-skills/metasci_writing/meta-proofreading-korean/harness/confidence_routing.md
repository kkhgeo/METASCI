# 층 라우팅 — 신뢰도에 따라 무엇을 다르게 하는가

> 원본 `meta-proofreading`의 `confidence_routing.md`를 대체한다. 영문판은 판정
> **신뢰도**에 따라 표시 방식을 바꾸지만, 한국어판은 **층 자체가 신뢰도 구간**이라
> 라우팅 축이 다르다.

---

## 1. 축이 왜 다른가

Kim, Taeryeong(2026)이 측정한 것은 개별 판정의 신뢰도가 아니라 **루브릭 명세성
수준별 신뢰도**다.

| 수준 | 평균 QWK | 이 스킬의 층 |
|---|---|---|
| 규칙 기반 (검증 가능·결정적 조건) | .915 | **L1** |
| 준거 참조 (명시적 기술어 + 판단) | .597 | **L2** |
| 판단 기반 (개방형 인상 평가) | .528 | **L3** |

즉 **항목을 어느 층에 배정하느냐가 곧 그 항목의 신뢰도 선언**이다. 배정이
라우팅이다.

---

## 2. 층별 라우팅

### L1 → 확정 표시, 사용자 확인 불필요

```
[L1 · 확정] R{n} {규칙명}
  원문 → 교정 → 근거(출처+쪽수)
```

사용자에게 선택을 묻지 않는다. 규칙 위반은 위반이다. 다만 **교정형 적용 여부는
저자가 정한다** — 지적과 적용은 다른 문제다.

**예외 — 확정에서 내려야 하는 경우**
- `sources.md` §4 인용 금지 목록에 걸림 → 지적 자체를 철회
- 교정형이 원문의 주장·수치·인용을 바꿈 → 철회
- 규칙에 명시된 예외 조건에 해당(예: R5 "어색하지 않으면 그대로 둔다",
  R2 무생물 주어 피동 허용) → 철회

### L2 → 과반이면 확정, 아니면 소수 의견

```
과반 지적       → [L2 · 확정]  준거명 + 배점 + 리뷰어 k/n
1인 지적        → [L2 · 소수]  확정 아님. 저자 참고용
과반 판정 불가  → [판정 불가]  무엇이 확인되면 판정 가능한지 명시
```

**LOW confidence는 확정하지 않는다.** 매뉴얼·지식 자원으로 확인할 수 없는 관행에
판정이 걸리면 `[판정 불가]`로 내리고, 웹 검색으로 보완 가능하면 검색어를 제안한다.

### L3 → 판정 없음, 항상 선택지

```
[L3 · 선택] {항목}
  원문 (맨 위) → 후보 A → 후보 B
  각각 gains / loses
  ※ 이 층은 판정하지 않습니다
```

confidence를 매기지 않는다. 판정하지 않으므로 판정 신뢰도도 없다.

---

## 3. 사용자가 L3 판정을 요구할 때

"어느 게 나아?"라고 물으면 **고르지 않는다.** 대신 이렇게 답한다.

> 이 층은 판정하지 않도록 설계되어 있습니다. 문장 연결성과 어휘 적절성은
> 인간 전문가끼리도 일치도가 QWK .48·.43 수준이라(Kim 2026), 단일 정답을
> 제시하는 것이 측정 가능한 근거를 넘어섭니다. 대신 각 후보가 무엇을 얻고
> 무엇을 잃는지를 다시 정리해 드리겠습니다.

그런 다음 트레이드오프를 **더 구체적으로** 다시 쓴다. 선택을 대신 해 주지는
않되, 선택에 필요한 정보를 늘리는 것은 이 스킬의 일이다.

사용자가 재차 요구하면 따르되, **"저자 요청에 따른 임의 선택이며 근거에 기반한
판정이 아님"**을 명시한다.

---

## 4. 층간 이동

항목이 잘못된 층에 있다고 판단되면 이동시키되 **방향에 제약이 있다.**

| 이동 | 허용 | 조건 |
|---|---|---|
| L3 → L2 | ○ | 매뉴얼에 명시적 준거와 출처가 있을 때만 |
| L2 → L1 | ○ | 조건이 결정적으로 검증 가능할 때만 |
| L1 → L2 | ○ | 예외 조건 해당 여부에 판단이 필요할 때 |
| L2 → L3 | ○ | 준거 적용에 근거를 못 댈 때 |
| **L3 → L1** | **×** | 두 단계 승격 금지 |

**승격(L3→L2, L2→L1)에는 출처가 필요하다.** 강등에는 필요 없다 — 모르겠으면
내리는 것이 안전하다.

이미 매뉴얼이 배정한 층을 바꾼 경우 **바꿨다는 사실과 이유를 출력에 남긴다.**

---

## 5. 웹 검색 보완

`config/session_management.md`의 검색 규약을 따르되, **층별로 목적이 다르다.**

| 층 | 검색 목적 |
|---|---|
| L1 | 규칙의 **출처 확인** — `sources.md` §6 후속 확보 목록 |
| L2 | 준거 적용에 필요한 **분야 관행 확인** |
| L3 | **하지 않는다** — 문체 선택은 검색으로 결정되지 않는다 |

검색이 불가능한 환경이면 "**[검색 불가]** 로컬 지식과 manual 기준으로만
진행합니다"를 명시하고 해당 항목을 `[판정 불가]`로 둔다.
