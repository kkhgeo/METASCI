# 한국어 AI 티 패턴 대응표 (ko-patterns)

> **출처**: [epoko77-ai/im-not-ai](https://github.com/epoko77-ai/im-not-ai) humanize-korean v2.3.0의
> taxonomy(10대 카테고리 × 70패턴)·실증 검증 노트를 이 스킬의 4-Layer 체계에 맞춰 압축 이식 (MIT License, 2026-08-10).
> 원본의 실증 근거: AI 3모델 생성문 60편 vs ChatGPT 공개 이전(2022-01-01 前) 한국어 산문 60편 대조 코퍼스, 로그우도비 G² 검정.
>
> **사용 시점**: 입력 텍스트가 한국어이면 PHASE 1 각 Layer 스캔과 PHASE 2 교정에서
> `ai-lexicon.md`/`naturalization-guide.md`의 영어 대응표 **대신** 이 파일을 쓴다.

**심각도**: [S1] 결정적(1회로 확신) / [S2] 강함(3회+ 반복 시 티) / [S3] 약함(중첩 시 강화).
**실증 마크**: ★ = 대조 코퍼스에서 통계적으로 확증된 패턴(G² p<0.01 이상).

## Do-NOT 리스트 (탐지·교정 모두 제외)

고유명사·제품명·기관명 / 수치·날짜·단위 / 큰따옴표 안 직접 인용 / 법률 조문 /
수학·화학·통계 표기 / 업계 표준 영어 약어(LLM·GPU·API 등) / 인용문헌 표기.

## Layer 매핑

| 이 스킬의 Layer | 이 파일의 카테고리 |
|---|---|
| Layer 1 Lexical (어휘) | A(번역투 어휘) · B(영어 병기) · D(관용구) · F(수식·중복) · I(형식명사) |
| Layer 2 Syntactic (구문) | A(번역투 구문) · E(리듬·균일성) |
| Layer 3 Discourse (담화) | G(Hedging) · H(접속사) |
| Layer 4 Formatting (서식) | C(구조·레이아웃) · J(시각 장식) |

## A. 번역투 (Translation-ese)

- **A-1** [S1] "~에 대해(서)" 남발 → 목적격 조사로 직결("X에 대해 논의" → "X를 논의")
- **A-2** [S2] "~를 통해/통하여" **문단 3회+ 반복 시에만** → 일부를 "~로", "~해서", "~함으로써"로 분산(1~2회는 보존 — 실증: 원어민이 오히려 2배 더 씀, 무조건 분산은 기각됨)
- **A-3** [S1] "~에 있어(서)" → "~에서" 또는 "~을 볼 때"
- **A-4** [S2] "~라는 점에서" 3회+ → "~서", "~라는 이유로"
- **A-5** [S2] "~와 관련하여/관련된" → "~에", "~의"
- **A-6** [S2] "~에 기반하여/바탕으로" 남발 → "~로", "~을 보고"
- **A-7** [S1] "가지고 있다"(have 직역) → 형용사·동사 환원("강한 경쟁력을 가지고 있다" → "경쟁력이 강하다")
- **A-8** [S1] 이중 피동 "~되어진다/~지게 된다" → 능동 또는 단일 피동("판단되어진다" → "판단된다")
- **A-9** [S2] "~에 의해" 피동 → 행위자를 주어로("AI에 의해 생성" → "AI가 만든")
- **A-10** [S2] "~할 수 있다" 남발 → 단언 가능한 곳은 단언
- **A-11** [S2] "~을 위해" 목적절 남발 → "~려고", "~도록", "~위한"
- **A-15** [S2] 추상 주어 + 만능 동사(보여준다/제공한다/가져온다) → 구체 주어로 환원; 인지 동사 직역(suggest/show)은 "~에 따르면 ~이다"
- **A-16** [S1] "그/그녀/그것/그들" 단락 3회+ — **영어 원문이 있는 번역 맥락에서만 발동**(자생 한국어 산문에서는 인간이 더 씀 — 발동 금지) → 생략(영형) 또는 명사구로
- **A-18** [S2] 명사 앞 3어절+ 관형구 좌향 수식 → 문장 분리 또는 후치 동격절
- **A-19** [S2] 이중 조사 "~에서의/~으로의/~에의" → 절·구로 풀어쓰기(단순 "~의"는 비대상)

## B. 영어 인용·용어 과다

- **B-1** [S2] 괄호 영어 병기 매번 반복 → 첫 등장만 병기, 이후 한글만
- **B-2** [S2] 설명 없이 낀 buzzword(seamless·robust·leverage) → 광고성만 한국어로 풀고, 표준 기술 용어는 원어 보존

## C. 구조적 AI 패턴 (서식·레이아웃)

- **C-1** [S2] "첫째, ~. 둘째, ~. 셋째, ~." 기계적 병렬 — 논설·에세이 장르에서만 신호(학술 보고서의 실제 열거는 보존)
- **C-2** [S2] 산문 장르에서 3개+ 연속 불릿 블록 → 문단 산문으로 통합
- **C-5** [S1] 이모지 남발 → 격식 장르면 전부 삭제
- **C-7** [S2] 문단 문두 "먼저-반면-결국" 3단 공식 → 접속사 1~2개로 줄임
- **C-8** [S1] ★ 대구 공식 "A인가, B인가"·"A가 아니라 B" 3회+ 반복 → 한 번만 살리고 나머지는 비대칭 평서문으로. **실증 최강 신호: AI가 인간의 9.2배(G²=41.7, p<0.0001), 개인 블로그 대비 18배. 세 모델 공통**
- **C-9** [S2] 숫자 괄호 인덱싱 "1) 2) 3)" → 본문에 녹이거나 어휘 변주
- **C-10** [S2] 콜론 부제 헤딩 "X: Y" 반복 → 단일 명사구로 압축(학술 보고서의 실제 절 제목은 보존)
- **C-11** [S1] ★ 연결어미(-고/-며/-지만/-면서/-아서) 직후 쉼표 → 쉼표 제거. 6회+ = 강한 신호(KatFish ACL 2025: 4.84배 분리도)
- **C-12** [S2] ★ 쉼표 과다 — 실증: AI 1.5배(G²=25.5), 쉼표 포함 문장 비율 1.4배

## D. AI 특유의 관용구

- **D-1** [S1] 결산 lexicon "결론적으로/요약하면/정리하자면" 3회+ → 1~2건만 남김
- **D-2** [S1] "시사하는 바가 크다/매우 중요하다" 의의 과장 → 삭제 또는 구체 결론으로
- **D-3** [S1] 열거 도입 "크게 세 가지로 나눌 수 있다" → 도입구 삭제, 바로 본론
- **D-4** [S1] hype 어휘(혁신적/획기적/전례 없는) 3회+ → 구체 수치·사실로 환원
- **D-5** [S2] 의인화 추상 주어("기술이 묻는다") → 사람·기관 주어로
- **D-6** [S2] 결말 공식 "~할 때입니다/~시점입니다" → 구체 동사 단언, 문서당 1회 이하
- **D-7** [S2] 변환 공식 "X에서 Y로/X을 넘어 Y로" 반복 → 직접 단언, 문서당 1회 이하

## E. 리듬·문장 길이 균일성

- **E-1** [S2] ★ 문장 길이 균일 — 실체는 **장문(100자+) 부재**(실증: 인간 91.3/1000문장 vs AI 8.1, G²=60.9) → 인접 문장을 이어 장문 1개를 문단마다(내용 추가 금지)
- **E-2** [S2] ★ 동일 종결어미 4문장+ 연속, "~한다" 편중(실증 1.8배) → 종결어미 다양화; "~고 있다"는 단순 시제로 환원 가능 시 환원
- **E-7** [S2] 청자 경어법(해라/해요/합쇼) 한 문서 내 혼재 → 격식 등급 하나로 일관

## F. 과도한 수식·중복

- **F-2** [S2] 동의어 이중 수식("중요하고 핵심적인 역할") → 하나만
- **F-4** [S2] 한자어 명사화 -성/-적/-화 누적(문서 12회+) → 동사·형용사 어근으로 환원
- **F-5** [S2] "~적 N" 추상 체인("전략적 함의") 3회+ → 명사+명사 또는 풀어쓰기

## G. 과도한 Hedging

- **G-1** [S2] 추측 종결 "~로 보인다/~로 판단된다" 남발 → 단언 가능한 곳은 단언. **단, 학술 원고에서 의도된 인식론적 hedging은 보존 — 저자 확인 없이 강화 금지**
- **G-2** [S2] 이중·삼중 완곡 "~할 가능성이 있을 수 있다" → 완곡 하나만
- **G-3** [S2] 균형 lexicon "양쪽 모두/장점도 있지만/신중하게" 4회+ → 한쪽 단언·구체 비교·조건부로

## H. 접속사 남발

- **H-1** [S1] 문두 접속사 "또한/따라서/즉/나아가" 5회+ → 대량 제거, 문장 자체가 흐름을 잡게
- **H-3** [S2] 메타 진입 "이는 ~/이 점에서" 3회+ → 본문에 녹이거나 삭제
- **H-4** [S2] "즉" 남발 → 변주 또는 생략, 문서당 2회 이하

## I. 형식명사·의존명사 과다

- **I-1** [S2] "~한 것이다/~일 것이다" — **연속 3회+ 남발 시에만** 일부 평서화(실증: 인간이 2배 더 씀, 무조건 평서화는 기각됨. 기본 보존)
- **I-2** [S2] "주목할 점은/X은 ~라는 점에 있다" → "X는 ~다" 직설로
- **I-3** [S2] "~다는 것이다/~다는 뜻이다" 결말 → "~다" 직접 종결, 합산 2회 이하
- **I-4** [S2] 권고형 결말 "~해야 한다/~할 필요가 있다" 5회+ → 구체 동사 단언·주체 명시·조건문 변주

## J. 시각 장식 남용

- **J-1** [S2] 문장마다 볼드 강조 → 격식 산문이면 본문 볼드 거의 제거
- **J-2** [S2] 따옴표 강조 5회+ → 진짜 인용만 남기고 평어로
- **J-3** [S2] 대시(—) 부가 설명 반복 → 쉼표·괄호·문장 분리로(원문에 이미 있던 대시는 보존)

## 관측 전용 신호 (진단 리포트에만 기록 — 처방 금지)

AI가 "못 쓰는 것"도 강한 신호지만, 없는 것을 만들어내는 처방은 의미 드리프트를 유발하므로 금지한다.

| 신호 | 실증 | 처리 |
|---|---|---|
| 직접 인용 결핍 | 인간 8.7 vs AI 0.0/1000문장 (G²=96.4) | 관측만 — **없는 인용을 지어내지 않는다** |
| 괄호 부연 결핍 | 인간 10.6 vs AI 1.2 (G²=69.5) | 관측만 |
| 과거형 회피("했다") | 인간 4.5배 (장르 교란 가능) | 관측만, 잠정 |

## 한국어 자체검증 체크리스트 (PHASE 2 Verification에 추가)

1. 고유명사·수치·날짜·인용 100% 보존 — 원문 대비 한 글자도 다르지 않은가
2. register 보존 (양방향) — 격식체→격식체, 구어→구어. '-했-'→'-하였-' 격식 상향도 금지
3. 잔존 S1 패턴 0건 — A-1·A-3·A-7·A-8·C-5·C-8·C-11·D-1~D-4·H-1
4. 빼기 전용 — 원문에 없던 비유·수사·상투구를 새로 심지 않았는가
5. 변경률 30% 이하 — 확정 판정은 `scripts/verify_gates.py`(자가 산출값은 참고용)
