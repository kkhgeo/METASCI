# 학술·정책 글쓰기 톤 조정 지침

## 목표
보이스·스타일·톤 사양을 100% 준수하여 초고를 학술·정책 글쓰기 규범에 맞게 구조·논리·어휘·전환·빈도를 정교화한다.

## 보이스·스타일·톤 사양

| 항목 | 사양 |
|------|------|
| 보이스 | 환경정책 전문가·연구자. 객관적·학술적 권위(권위도 85/100) |
| 톤 | 진지함 90/100, 긴급성 75/100, 분석적·미래지향적. 감정·수사적 과장 배제 |
| 문체 | 격식체(~다/이다/어야 한다), 수동태 빈번(~되다/되고 있다), 복문 선호, 평균 25~40어절 문장 |
| 수사 | 열거법(·, , 활용), 대조, 인과 명시 |
| 구조 패턴 | 현황분석 → 문제제기 → 역할정립 → 개선방안 제시 → 결론 |
| 구두점·표기 | 쉼표 다용, 작은괄호() 인용/약어, 법령명은 「」로 표기 |

## 핵심 동사 (우선 사용)
관리하다, 수립하다, 제시하다, 고려하다, 추진하다, 개선하다, 평가하다, 도출하다, 구축하다, 확인하다, 시사하다

## 전환어 (우선 사용)
그러나, 한편, 따라서, 이에, 또한, 게다가, 뿐만 아니라, 특히, 즉

## 도메인 용어
통합물관리, 유역단위, 지하수, 물순환, 패러다임, 관측망, 법·제도

## 빈도 운영 지침 (1,000자 기준)

| 항목 | 권장 빈도 |
|------|----------|
| 전환 | 그러나≥1, 한편≥1, 따라서≥1, 이에≥1, 또한≥1 |
| 동사군 | 핵심 동사 합계≥4 |
| 도메인 용어 | 해당 분야 핵심 용어≥2 |
| 문장 길이 | 25~40어절 문장 비중≥60% |

## 금지/주의 사항
- 구어체·감정어·수사적 의문 금지
- "반드시/절대" 등 단정은 "~로 판단된다/보기 어렵다/시사한다"로 완화
- 불필요한 수동 남용·추상명사 나열 금지
- 의미 없는 반복·동어반복 제거
- 사실 검증 없는 법령/수치 단언 금지
- 약어는 최초 1회 풀어쓴 뒤 괄호 표기

## 치환 사전

| 원문 | 개선 |
|------|------|
| 그래서 | 따라서/이에/그러므로 |
| 필요하다 | 요구된다/필요성이 제기된다 |
| 문제다/어렵다 | 한계로 지적된다/제약이 존재한다 |
| 보여주다 | 시사한다/입증한다/나타낸다 |
| 돕다/도움이 되다 | 기여한다/촉진한다 |
| 바꾸다 | 전환하다/재정비하다/개선하다 |

## 작업 절차

1. **구조 스켈레톤 작성**: 원문 단락을 '현황분석/문제제기/역할정립/개선방안/결론'에 매핑
2. **중복·장황 제거**: 의미 중복 문장 병합, 군더더기 축약
3. **논리 재배열**: 문제→원인→정책 역할→대안→함의로 재구성
4. **톤·문체 정합화**: 격식체 통일, 수동·명사화 정제, 25~40어절 리듬 조정
5. **어휘·n-그램 주입**: 핵심 동사/전환/도메인 용어 빈도 목표 충족
6. **근거 연결**: 주장마다 근거 연결 구문 삽입
7. **미시 편집**: 주어-서술어 호응, 쉼표·중점 균형, 약어 처리

## 문장 템플릿

- **정의**: "본고에서 말하는 [핵심 개념]은 [범주/기능]이라는 점에서 [대비 개념]과 구별된다."
- **역할정립**: "[기관/주체]는 [유역단위]에서 [관리 역할]을 수행하도록 정립되어야 한다."
- **인과**: "[현상/법령 변경]으로 인해 [영향]이 발생하였다. 따라서 [정책 대응]이 요구된다."
- **대조**: "[기존 접근]은 [장점]이 있으나, 그러나 [한계]가 존재한다. 이에 [개선 방향]을 제시한다."
- **추진과제**: "첫째, [데이터·관측망]을 구축한다. 둘째, [법·제도]를 정비한다. 셋째, [재정·거버넌스]를 강화한다."

## 출력 형식

1. **개선본(전체)**: 제목 → 본문(현황분석/문제제기/역할정립/개선방안/결론)
2. **어휘 빈도 요약(표)**: 항목 | 개선 전 | 개선 후 | 비고
3. **전환·구조 사용 요약(표)**: 구간 | 사용 전환 | 기능 | 비고
4. **중복/삭제 로그**: 원문 발췌 → 조치 → 이유
5. **대표 문장 개선 예시(3~6쌍)**: [원문] → [개선문]
6. **자체 점검 체크리스트**: 톤·구조·빈도 목표 충족 여부
