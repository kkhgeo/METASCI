# 섹션별 구성 판단 기준

문장을 쓰기 전에 **어떤 내용이 어디에 있어야 하고, 어떻게 연결되어야 하는가**를
판단한다. 문장 표현·인용 형식·수치 보고의 세부사항은 집필과 교정 단계에서 본다.

## 적용 원칙

- 논의 중인 섹션만 읽는다. ★는 먼저 검토할 항목이다. 질문과 문제 지적은
  중요도에 따라 묶고, 전체 검토에서는 필요한 내용을 빠뜨리지 않는다.
- 아래 순서는 유용한 기본형이다. 연구 유형·원고 형식·투고처에 맞는 다른 순서도
  가능하다. 순서 차이보다 독자의 이해나 논증에 생기는 문제를 설명한다.
- 섹션에 필요한 요소를 모든 단락에 요구하지 않는다. 부분 초고만 있을 때는
  보이지 않는 내용을 누락으로 단정하지 않는다.
- **자료가 없음과 아직 확인하지 못함을 구분한다.** 실제 결손이면 삭제·자료 요청·
  주장 축소를 논의한다. 구체적인 출력 표시는 `map-format.md`를 따른다.
- 자료가 배정돼 있어도 해당 주장을 뒷받침하는지 본다. 요약·추출본만 읽었다면
  원문까지 확인한 것처럼 말하지 않는다. 확인 깊이는 해당 주장에 맞춘다.
- 설명 보완과 새 분석·자료수집·검증의 필요를 구분한다. 후자는 구성표에 넣는
  것만으로 해결되지 않으며 이미 수행한 연구처럼 써넣지 않는다.
- 아래 출처 ID는 판단 기준의 계보이다. 실험적으로 검증된 법칙이나 원문 직접
  인용을 뜻하지 않는다. 실제 구조 문제와 유효한 대안에 대한 선호를 구분한다.

## 독자·리뷰어 관점의 공통 점검

대화에 참여하지 않은 독자가 원고를 읽는 상황을 기준으로, 현재 요청한 수준에서
관련된 질문을 적용한다. 독자의 배경은 원고 유형·대상 학술지·대화에서 파악하고,
구성을 바꿀 만큼 중요한 불확실성만 확인한다. 아래 항목은 고정 구성이나 추가 출력 양식이 아니다.

- **무엇을 이해시키려는가:** 요청하거나 합의한 주제·질문·핵심 메시지가 각 부분의
  선택과 순서에 반영되는가. 해당 범위를 다 읽으면 어떤 답이나 이해에 도달하는가.
  아직 답이 정해지지 않았다면 질문과 판단에 필요한 내용을 구성하고 결론을 미리 확정하지 않는다.
- **필요한 정보를 제때 만나는가:** 새로운 개념·비교·해석을 이해할 배경과 기준을
  앞선 내용이나 독자의 지식에서 확보할 수 있는가. 대화에서만 공유한 전제는 원고에
  필요한 만큼 배정한다. 익숙한 내용부터 시작하는 것은 기본 방향이지 고정 순서가 아니다.
- **각 부분의 역할과 연결이 읽히는가:** 한 부분의 관련 내용들이 일관된 목적을
  이루며 다음 부분을 준비하는가. 여러 관련 아이디어를 억지로 나누거나 모든 단락에
  배경·근거·결론을 반복하지 않는다. 연결어를 빼도 내용 사이의 관계를 설명할 수 있어야 한다.
- **근거에서 주장으로 가는 길이 보이는가:** 리뷰어가 주장·근거·이를 잇는 전제를
  찾아 평가할 수 있는가. 필요한 비교 기준·가정·조건을 배정한다. 설명의 생략과
  근거 자체의 부족을 구분하며, 순서 변경이나 도식의 화살표로 근거 부족을 해결하지 않는다.
- **누구의 지식과 기여인가:** 선행 문헌이 알려주는 사실, 이번 연구의 결과,
  저자의 해석·제안이 구분되는가. 문헌 목록을 늘리는 대신 무엇을 함께 뒷받침하고
  무엇을 미해결로 남기는지 구성한다.
- **빼거나 더하면 무엇이 달라지는가:** 한 부분을 빼면 주장·근거·조건·이해의 연결 중
  무엇을 잃는가. 필요한 배경과 한정 조건은 남기고 기능 없는 반복은 줄인다.
  예상 질문이나 대안 설명은 답의 의미·타당성을 실질적으로 바꿀 때만 다룬다.

리뷰어 관점은 구성의 설명 가능성을 점검하는 것이지 실제 심사 결과를 예측하거나
모든 반론을 선제적으로 추가하는 작업이 아니다. 판단을 바꾸지 않는 취향은 결함으로
취급하지 않는다. 점검을 위해 문장 수준으로 범위를 자동 확장하지 않는다.

## Title / 제목

- **제목이 약속하는 대상·관계·범위를 연구가 다루는가** ★ — 장소·기간·대상·
  설계가 범위를 결정한다면 필요한 만큼 반영한다. [TA1–TA2]
- 주제형과 결과형 모두 가능하다. 결과형이 근거보다 강한 인과·확실성·일반성을
  약속하지 않는지 본다. 길이·약어 등은 집필·투고처 확인 단계에서 다룬다.

## Abstract / 초록

기본 흐름: 맥락·목적 → 핵심 접근 → 주요 결과 → 결론. 논문 유형과 투고처에
맞춘다. Nature 등의 특정 템플릿을 모든 초록의 필수 형식으로 적용하지 않는다.

- **선택한 목적에 대응 결과가 있고 결론이 그 결과에서 나오는가** ★ [TA3]
- **핵심 질문에 답하는 결과를 대표성 있게 골랐는가** ★ — 가장 큰 차이나 작은
  P값만 고르지 않는다. 빠지면 결론이 달라지는 음성·반대 결과도 배정한다. [TA4]
- 본문이나 그림을 찾아보지 않아도 문제·접근·결과·답을 이해할 내용이 있는가. [TA5]
- 분량에 맞지 않으면 요소를 늘리기보다 선택할 목적과 결과를 조정한다.
  본문과의 일치는 `structural-integrity.md` 4번에서 본다.

## Introduction / 서론

기본 흐름: 관련 맥락 → 현재 지식 → 미해결 문제 → 목적과 기여.

- **무엇이 미해결이고 어떤 설명이나 판단을 제한하는가** ★ — 특정 장소에서
  연구가 없다는 사실만으로 필요성을 세우지 않는다. 그 장소·조건이 질문에
  중요한 이유를 밝힌다. 의미 있는 재현 연구도 필요성을 가질 수 있다. [IN1]
- **목적이 구체적이며 설계로 다룰 수 있는가** ★ — 기작의 공백을 제기하면서
  분포만 측정한다면 실제로 답할 수 있는 기여를 명확히 한다. 실제 가설이 있는
  연구는 가설을, 탐색적 연구는 탐색적 목적을 보존한다. [IN2]
- 문헌을 아이디어·발견·방법·불일치로 묶고, 각 묶음이 무엇을 알려주거나
  미해결로 남기는지 설명할 자리가 있는가. [IN3]
- 배경 단락이 다음 논의를 준비하는가. 일반적 배경도 독자에게 필요한 정의와
  맥락을 제공한다면 유지한다. [IN5]
- 서론 안 문헌검토는 연구의 필요성에, 독립 문헌고찰은 개념 틀이나 증거 종합에
  맞춰 배치한다. 리뷰 논문은 검토 범위와 기존 리뷰와의 관계를 밝힌다.
  검색·선정 절차는 해당하는 방법 절에 배정한다. [IN4]

## Methods / 연구 방법

실제 연구 과정 또는 분석 구조에 따라 설계·자료·처리·측정·모형·분석을 연결한다.

- **입력 자료 → 수행한 처리·측정 → 산출값을 따라갈 수 있는가** ★ — 직접
  측정한 값과 계산한 값을 구분한다. 비통상적 선택과 방법 변경의 이유를 배정한다. [ME1]
- **절차 재현과 결과 이해에 중요한 내용이 배정돼 있는가** ★ — 연구에 따라
  표집, 품질관리, 결측 처리, 변환, 가정, 보정, 모형 평가, 불확실성 등을 선택한다.
  빠지면 어떤 다른 절차나 해석이 가능해지는지 설명할 수 있을 때 결손으로 짚는다. [ME2]
- 본문에는 분석을 이해할 설명을 두고 긴 세부사항은 보충자료나 명확히 연결된
  방법 자료에 배정한다. 매개변수 목록을 구성표에 늘어놓지 않는다. [ME2–ME3]
- 윤리·등록, 고찰의 검색·선정, 질적 연구의 접근법, 모형의 입력·평가는 해당
  연구에 필요한 경우 적용한다. 통계 단락의 위치를 고정하지 않는다. 자료·코드
  공개 진술은 원고가 정한 위치에 배정할 수 있다. [ME5–ME6]
- 수행한 절차와 사전 계획·사후 변경을 사실대로 구분한다. 빠진 분석이 필요하면
  추가 연구 사안으로 밝히며 이미 수행한 절차처럼 구성하지 않는다. [ME3–ME4]
- 결과에 필요한 방법의 대응은 `structural-integrity.md` 2번에서 확인한다.

## Results / 연구 결과

- **질문·분석 또는 설명 가능한 순서로 결과 묶음을 배치했는가** ★ — 무엇과
  무엇을 어느 집단·장소·기간에 걸쳐 비교하는지 알 수 있는가. 집단 내 변화와
  집단 간 차이를 구분한다. [RE1]
- **생략하면 결론의 방향·범위·강도가 달라지는 결과가 빠지지 않았는가** ★ —
  관련된 음성·불리한·예상 밖 결과를 포함한다. 일부 자료만 보고 선택적 보고를
  단정하지 않는다. [RE3]
- 본문은 발견과 읽을 곳을 안내하고, 표는 정확한 비교, 그림은 패턴과 관계를
  드러내도록 배정한다. 핵심 수치의 재언급은 허용하되 시각자료 전체를 본문에
  재나열하지 않는다. [RE5]
- 관찰과 원인 설명의 자리를 구분한다. 분리형은 기작·문헌 비교·함의를 주로
  논의에 배정한다. Results and Discussion 통합형은 관찰 뒤에 해석을 둘 수
  있지만 그 설명의 근거를 구분한다. [RE4]
- 추가 추정·검정의 필요는 집필 문제가 아닌 추가 분석 사안으로 남긴다. [RE6]

## Discussion / 논의

기본 흐름: 연구 질문에 대한 답 → 해석·선행연구 비교 → 함의·한계와 미해결 문제.
각 기능의 순서는 논증에 맞출 수 있다.

- **결과를 재나열하는 데 그치지 않고 그 결과가 뜻하는 바를 설명하는가** ★ [DI1]
- **관찰 → 제안한 설명 → 설명을 뒷받침하는 근거가 연결되는가** ★ — 직접
  검증한 기작, 문헌이 뒷받침하는 가능성, 미검증 가설을 구분한다. 해석을
  실질적으로 바꿀 대안적 설명을 다루되 형식적으로 반론을 추가하지 않는다. [DI2]
- 선행연구와 무엇이 같거나 다른지, 그 차이를 설명할 근거가 있는지 다룬다.
  중요한 환경·대상·규모·설계·측정·분석 조건을 비교한다. 구체적인 방법상 한계는
  공정하게 비판할 수 있으며 자기 연구의 강점 홍보로 대체하지 않는다. [DI3]
- **한계가 어떤 추정·기작·인과 해석·일반화를 제한하는지 설명할 자리가 있는가**
  ★ — '표본이 작다' 같은 이름만 나열하지 않는다. [DI4]
- 실무·정책 제언이나 더 넓은 적용에 필요한 가정·조건을 다루는가.
  향후 연구는 실제로 남은 질문이나 한계와 연결한다. [DI5]
- 주장 범위와 강도는 각 근거와 설계에 맞춘다. 일괄적인 중간 강도를 요구하지
  않는다. 서론의 질문·공백에 대한 답변은 `structural-integrity.md` 1번에서 본다.

## Conclusion / 결론

별도 결론 절 또는 논의의 마무리에 적용한다.

- **발견을 종합하면 연구 질문에 무엇이라고 답할 수 있는가** ★ — 결과 목록을
  넘어 발견 사이의 관계가 최종 답에 기여하는가. [CO1]
- 본문에 전개하지 않은 결과·해석을 처음 도입하지 않는다. 각 결론의 근거 위치는
  `structural-integrity.md` 5번에서 확인한다. [CO2]
- **빠지면 답의 확실성이나 적용 범위가 달라지는 조건이 남아 있는가** ★ —
  모든 한계를 반복할 필요는 없지만 결론의 의미를 바꾸는 조건은 유지한다. [CO3]
- 근거가 뒷받침하는 기여로 마무리한다. 정책 제언이나 향후 연구를 의무적으로
  붙이지 않는다. 인용 개수 등의 형식은 투고처에 따른다. [CO4]

## 학위논문·연구계획서에 적용할 때

- 학위논문은 기관 형식과 실제 논증에 맞춰 장을 배치한다. 문헌고찰이 증거를
  종합하여 질문이나 개념 틀로 이어지는지, 장별 역할이 불필요하게 중복되는지
  본다. 특정 5장 구성을 의무화하지 않는다.
- 연구계획서는 문제·필요 → 검증 가능한 목표 → 방법·실행 가능성 → 기대 기여의
  연결을 본다. 목표와 방법, 관찰한 결과와 기대 성과를 구분한다.
- 일정·예산·자원·예상 난점·대안은 공모나 기관이 요구하거나 실행 가능성 판단에
  필요할 때 배정한다. 완료된 연구 논문의 필수 항목으로 옮기지 않는다.

`meta-rewriting` 3.0.0의 `references/principles.md`와 `references/sections/`에서
구성 단계에 적용 가능한 판단을 선별·재서술했다. 이 문서는 독립적으로 사용하며,
리라이팅 매뉴얼 전체를 읽거나 복사할 필요가 없다.

- 적용 원칙: 공통 원칙 §§1.1–1.4, 6.2–6.4; source-use의 SO1–SO4; ME4·RE6.
- 독자·리뷰어 공통 점검: 공통 원칙 §§1.2, 1.4, 2.1–2.3, 2.5, 4.1–4.4;
  IN5, ME2, DI1·DI5, CO1, SO2를 구성 수준으로 재서술한 편집적 종합이다.
- TA: title-abstract, IN: introduction, ME: methods, RE: results,
  DI: discussion, CO: conclusion의 동일 번호 항목.
- 학위논문·계획서는 기존 mapping의 범위를 유지한 편집적 정리이며 rewriting에서
  새로 검증한 규범으로 취급하지 않는다.
- 원문 계보는 rewriting의 `references/source-records/`에 남아 있다. 위 질문에는
  편집적 판단이 포함되므로 특정 논문의 직접 주장으로 인용하지 않는다.
  원문 인용이나 실증적 근거를 주장할 때는 해당 출처를 확인한다.
- 상류 변경 시 구성 판단에 영향을 주는 항목만 대조한다. 통째로 덮어쓰거나
  문장 교정 규칙을 다시 유입시키지 않는다.

**Version**: 2.4.0
