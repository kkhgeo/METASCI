# Objective Articulation Patterns

Patterns for research objective statements. Reference during Stage 2 Generation for P5 as needed.

## 1. Hierarchical
```
Our primary objective was to [main goal],
with secondary aims to (1) [sub-goal A] and (2) [sub-goal B].
```

## 2. Integrated / Simultaneous
```
We combined [method A] with [method B]
to simultaneously [goal 1] and [goal 2],
enabling [unique capability].
```

## 3. Progressive / Sequential
```
We first [established/characterized] [baseline],
then [investigated/quantified] [relationship],
and finally [determined/evaluated] [outcome/application].
```

## 4. Hypothesis-Driven
```
We hypothesized that [mechanism/relationship],
predicting that [testable prediction].
To test this, we [approach] across [scope].
```

## 5. Question-Based
```
Specifically, we addressed three questions:
(1) [What/How/To what extent] does [variable] affect [outcome]?
(2) [What/How/To what extent] ...?
(3) [What/How/To what extent] ...?
```

## 6. Novelty-Emphasized
```
Here, we present [novel approach/dataset/framework]
that [unique capability], providing [new insight]
into [process/system] at [unprecedented scale/resolution].
```

## Closing Signals (after objective statement)
```
- Our findings advance understanding of [topic]
  and provide [practical/theoretical contribution].
- This work contributes to [field] by [specific advance],
  with implications for [application/policy].
- The results inform [management/prediction/theory] of [system]
  under [changing conditions/scenarios].
```
