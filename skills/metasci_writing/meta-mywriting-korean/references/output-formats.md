# 출력 형식: Gap Analysis & 리라이팅 모드

PHASE 3 (Gap Analysis) 및 PHASE 4 (리라이팅 적용)에서 사용한다.

---

## PHASE 3: 이중 Gap Analysis 카드

```
================================================================
  이중 GAP ANALYSIS
  초고 vs 나의 스타일 Blueprint | 문서 유형: [유형]
================================================================

━━━ Part A: 스타일 일치도 (Dim 1–6) ━━━

잘 맞는 부분:
  - [차원]: [잘 되고 있는 점]
  - [차원]: [잘 되고 있는 점]

수정 필요:
  | 차원              | 초고 현재 상태          | Blueprint 기준              | 수정 예시                    |
  |-------------------|------------------------|----------------------------|------------------------------|
  | 어조 & 격식       | [진단 내용]            | [목표 행동]                 | "원문" → "수정안"            |
  | 문장 구조         | [진단 내용]            | [목표 행동]                 | "원문" → "수정안"            |
  | 논리 흐름         | [진단 내용]            | [목표 행동]                 | [구조 변경 설명]             |
  | 전환 표현         | [진단 내용]            | [목표 행동]                 | "원문" → "수정안"            |
  | 어휘 & 용어       | [진단 내용]            | [목표 행동]                 | "원문" → "수정안"            |
  | 인용 & 근거       | [진단 내용]            | [목표 행동]                 | "원문" → "수정안"            |

스타일 일치 점수 (10점 만점):
  어조 & 격식:     [X]/10
  문장 구조:       [X]/10
  논리 흐름:       [X]/10
  전환 표현:       [X]/10
  어휘 & 용어:     [X]/10
  인용 & 근거:     [X]/10
  -------------------------
  스타일 평균:     [X]/10

━━━ Part B: AI 패턴 스캔 (Dim 7) ━━━

탐지된 AI 패턴:
  | # | 패턴 유형       | 위치           | 탐지 내용                    | 대체 제안                    |
  |---|----------------|----------------|------------------------------|------------------------------|
  | 1 | 필러 표현       | P2-S1          | "~에 있어서"                  | 삭제 또는 "~에서"            |
  | 2 | AI 선호 어휘    | P3-S3          | "다양한 노력"                | 구체적 내용으로 교체          |
  | 3 | 과잉 헤징       | P5-S2          | "~것으로 판단된다"            | "~로 판단된다"               |

자연스러움 점수 (Dim 7, 50점 만점 · 높을수록 AI 흔적 적음):
  직접성:         [X]/10
  리듬:           [X]/10
  구체성:         [X]/10
  자연스러움:     [X]/10
  밀도:           [X]/10
  -------------------------
  자연스러움 합계: [X]/50

━━━ 종합 판단 ━━━

  스타일 일치도: [X]/10 | AI 자연스러움: [X]/50
  권장 모드: [A: 문장별 피드백 / B: 전면 리라이팅]
  우선 처리 차원: [가장 낮은 점수 차원 2-3개]
```

### 점수 해석

> 이 표는 `SKILL.md`의 "점수 해석 & 모드 권장" 표와 **동일**해야 한다. 한쪽만 고치지 말 것.

| 스타일 평균 (Dim 1-6, /10) | 자연스러움 (Dim 7, /50) | 권장 모드 |
|---|---|---|
| 8-10 | 35-50 | Mode A — 미세 수정 (이미 스타일 부합) |
| 8-10 | 35 미만 | Mode A — AI 패턴 제거 중심 |
| 5-7  | 35-50 | Mode A — 스타일 차이 보정 중심 |
| 5-7  | 35 미만 | Mode B — 스타일 + AI 제거 동시 |
| 4 이하 | 무관 | Mode B — 전면 리라이팅 |

**모드 결정 우선순위:** 사용자가 A/B를 명시적으로 지정했으면 점수와 무관하게 그 모드로, 미지정 시 위 권장을 따른다.

## PHASE 4 Mode A: 문장별 피드백

초고를 단락 순서대로 처리한다. 모든 단락을 다룬다.

### 수정 필요 문장

```
━━━ P[N] ━━━

[원문]
"정확한 원문 텍스트"

[수정]
"수정된 버전"

[근거]
- [Dim N: 차원명]: [적용된 Blueprint 규칙 + Blueprint에서 인용한 참조 예시] (1-2줄)
```

### AI 패턴 제거 문장

```
[원문]
"AI 패턴이 포함된 원문"

[수정]
"AI 패턴 제거 + 스타일 적용"

[근거]
- [Dim 7: Anti-AI]: [탐지된 패턴명] → [제거 방법]
- [Dim N: 차원명]: [동시 적용된 스타일 규칙] (있을 경우)
```

### 유지 문장

```
✓ P[N]-S[M]: 유지 (Blueprint 기준 부합)
```

### 처리 규칙
- Gap Analysis에서 가장 낮은 점수 차원부터 우선 처리
- 수정 불필요한 문장은 리라이팅하지 않는다
- 각 수정에 적용된 차원 번호를 반드시 명시
- AI 패턴 제거 시 "[AI 패턴 제거]" 태그 추가
- 한 문장에 여러 차원 적용 가능 (모두 명시)

## PHASE 4 Mode B: 전면 리라이팅

전체 입력을 리라이팅한다. 7차원 모두 적용.

### 보존 원칙
- 원문의 모든 **주장**(argument) 보존
- 모든 **데이터 포인트** 보존 (수치, 단위, 불확도)
- 모든 **인용**(citation) 보존
- **표/그림** 참조 번호 유지
- 과학적/정책적 **의미 변경 절대 금지**
- **스타일만** 변환한다

### 리라이팅 출력

```
━━━ 리라이팅 결과 ━━━

[리라이팅된 전체 텍스트]
```

### 변경 요약표

```
━━━ 변경 요약 ━━━

| 변경 유형           | 건수 | 대표 예시                                    |
|---------------------|------|----------------------------------------------|
| 어조 조정 (Dim 1)   | N    | 비격식 → 격식 해라체                          |
| 문장 재구성 (Dim 2)  | N    | 단문 나열 → "~하여 ~하는" 복합문              |
| 논리 재배치 (Dim 3)  | N    | 주장→근거→해석 순서로 재배열                   |
| 전환어 추가 (Dim 4)  | N    | "따라서", "한편" 삽입                         |
| 어휘 교체 (Dim 5)    | N    | "보여준다" → "나타난다"                       |
| 인용 형식 (Dim 6)    | N    | 법률 인용 「」 형식 적용                       |
| AI 패턴 제거 (Dim 7) | N    | 필러 삭제, AI 어휘 교체, 헤징 정리            |

━━━ 보존 확인 ━━━
주장 보존: ✓  |  데이터 보존: ✓  |  인용 보존: ✓
```

### 사후 검증 체크리스트

리라이팅 완료 후 자체 검증:
1. [ ] 원문의 모든 주장이 리라이팅에 존재하는가?
2. [ ] 모든 인용이 보존되었는가?
3. [ ] 데이터 수치가 변경되지 않았는가?
4. [ ] 7개 차원이 모두 반영되었는가?
5. [ ] 자연스러운 한국어로 읽히는가? (기계적 치환이 아닌가?)
6. [ ] AI 패턴이 제거되었는가?

```

| # | 원문 | 수정 | 적용 차원 |
|---|------|------|----------|
| 1 | "원문 문장 1" | "수정 문장 1" | Dim 1, 7 |
| 2 | "원문 문장 2" | "수정 문장 2" | Dim 2, 5 |
| ... | ... | ... | ... |
```
