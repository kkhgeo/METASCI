### H-3. Top 5 Most Distinctive Cross-Section Shifts

1. **당위 표현(~해야 한다) 밀도**: SEC01(1건) → SEC02(0건) → SEC03(3건) → SEC04(6건) → SEC05(4건). 개요·현황에서는 거의 없고, 과제·맺음말에서 급증하여 제언의 강도가 뒤로 갈수록 강해진다.

2. **인용 패턴 유형 전환**: SEC01은 법률(「법명」) 인용이 지배적이고, SEC02는 통계·기관 인용 중심이며, SEC03에서 국내외 학술문헌+법률이 혼합 인용되고, SEC04-05에서 인용이 크게 줄어든다.

3. **피동 구문 용도 전환**: SEC01-02에서는 제도·현황 기술용 피동(~포함된다, ~수립되었다, ~예상된다)이 사용되나, SEC03에서는 문제 지적용 피동(~활용되지 못하고, ~운영되는)으로, SEC04-05에서는 당위적 피동(~요구된다, ~적용되어야 한다)으로 기능이 변화한다.

4. **순서 표현**: SEC01-03에서는 ①②③ 원문자를 사용하고, SEC04에서만 "첫째, 둘째, 셋째, 넷째" 서수사 나열을 사용하여 과제를 체계적으로 구조화한다.

5. **문두 전환어 변화**: SEC01-02는 '따라서', '즉' 등 인과·부연 위주이나, SEC03에서 '하지만' 대조 표현이 등장하고, SEC04에서 순서 표현이 지배적이 되며, SEC05에서 '앞으로', '이를 위해' 등 전망·수단 표현으로 전환된다.

### I-3. Korean-Specific Style Rules

#### 문체/어조(Tone) Rules

| Rule | Description | Evidence |
|------|-------------|----------|
| **격식체 서술문 일관 사용** | 전 섹션에서 ~이다/~있다/~한다 격식체 서술 종결어미를 사용한다. ~입니다/~합니다 경어체는 전혀 사용하지 않는다. | 전체 문서 [EX#1] |
| **비인칭 주어 지배** | 인칭 주어(우리, 저자 등) 대신 제도/계획/법률이 문장 주어로 사용된다. 유일한 예외: "우리나라는" (국가 주어). | "하천기본계획은...", "전략환경영향평가는..." [EX#1-전체] |
| **~하였다 vs ~했다** | "~하였다" 격식 과거형만 사용되며, "~했다" 비격식 과거형은 사용되지 않는다. | "제언하였다" [EX#1-SEC05] |

#### 조사 사용 패턴

| Pattern | Description | Evidence |
|---------|-------------|----------|
| **은/는 (주제 표지)** | 주요 개념의 첫 등장 시 "은/는"으로 주제화: "하천기본계획은", "전략환경영향평가는" | [EX#1-전체] |
| **이/가 (새 정보)** | 신정보 도입 시 "이/가" 사용: "필요성이 꾸준히 제기되고", "대안평가가 요구된다" | [EX#1-SEC03, SEC04] |
| **을/를 + 동사 연쇄** | "~을 확인하고, ~을 검토하여, ~을 도모하는" 등 목적어+동사 연쇄가 빈번 | [EX#1-전체] |
| **에 대한 (관계 표지)** | "~에 대한"이 매우 빈번하게 사용되어 주제 한정: "하천기본계획에 대한 전략환경영향평가" | [EX#1-전체, 제목 포함] |
| **으로서 (자격)** | "~으로서" 자격 표현: "정책 수단으로서", "법정계획으로서" | [EX#1-SEC01, SEC02] |

#### 한자어 vs 고유어 비율

| Category | Ratio | Examples |
|----------|-------|---------|
| **한자어 명사** | ~85% | 전략환경영향평가, 적정성, 타당성, 계획과정, 의사결정, 이해당사자 |
| **고유어 명사** | ~5% | 가(가를 고찰하고), 것(것으로 예상된다), 바(보고한바 있다) |
| **외래어** | ~10% | 거버넌스, IWRM, SEA, IAIA |
| **한자어 동사** | ~80% | 규정하다, 도모하다, 제언하다, 일원화하다, 연계하다 |
| **고유어 동사** | ~20% | 갖는다, 돕는다, 이른다, 남겨져 |

#### 연결어미 패턴

| 연결어미 | 기능 | 빈도 | Example | Source |
|--------|------|------|---------|--------|
| ~하여 / ~하여서 | 순차/인과 | 매우 높음 | "검토하여 국토의 지속가능한 발전을 도모하는" | [EX#1-SEC01] |
| ~하고 | 병렬/나열 | 높음 | "고찰하고, 역할 확대에 대하여 제언하고자 한다" | [EX#1-SEC01] |
| ~하며 | 병렬/동시 | 중간 | "분포하며 이는 총 연장..." | [EX#1-SEC02] |
| ~함으로써 | 수단/방법 | 낮음 | (직접 출현 빈도 낮음, ~하므로 형태 사용) | - |
| ~하므로 | 이유/근거 | 중간 | "반영하는 제도이므로 물관리 계획에 대한" | [EX#1-SEC03] |
| ~하되 | 조건/양보 | 낮음 | "반영을 기본으로 하되, 환경현황과" | [EX#1-SEC04] |
| ~하도록 | 목적 | 중간 | "도모하도록 계획을 평가하는" | [EX#1-SEC03] |

| Pattern | Function | Example | Source |
|---------|----------|---------|--------|

## J. Appendix: Global Style Fingerprint Summary

### 1. 문서 전체 톤 (Overall Tone)
- **격식적 정책 서술문체**: ~이다/~있다/~한다 종결어미 일관 사용
- **비인칭 제도 중심 서술**: 주어는 항상 제도·법률·계획·평가
- **한자어 지배적 어휘**: 전문 용어의 85%+ 한자어
- **점진적 당위 강화**: 개요(약) → 현황(없음) → 역할(중간) → 과제(강) → 맺음말(강)

### 2. 핵심 문체 패턴 5선
1. **법률 인용 공식**: 「법명」에 따라/에서는/에 의거 → 정의·근거 제시
2. **목적 공식**: ~의 목적은 ~ 측면에서 ~을 확인하여 ~를 도모하는 데 있다
3. **문제-해결 공식**: 하지만 ~되지 못하고 → 따라서 ~해야 한다
4. **과제 나열 공식**: 첫째/둘째/셋째/넷째 + ~필요가 있다/~해야 한다
5. **결론 공식**: 따라서 → 나아가 → 앞으로 → 즉 → 이를 위해 ~요구된다

### 3. 피해야 할 표현
- 1인칭 주어 (나, 우리 연구팀, 필자)
- 비격식 과거형 (~했다, ~됐다)
- 경어체 (~입니다, ~합니다, ~습니다)
- 구어체 전환어 (그래서, 그런데, 근데)
- 모호한 정도 표현 (많이, 좀, 꽤)
