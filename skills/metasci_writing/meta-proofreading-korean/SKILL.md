# Meta-Proofreading-Korean — 명세성 3층 심의 교정

## 0. 이 스킬이 존재하는 이유

한국어 원고 검토에는 **비어 있는 층**이 있다. 근거는 셋이다.

1. **국가 공식 진단 체계가 내용의 논리구조를 측정하지 못한다.** 국립국어원
   『2019년 중앙행정기관 공공언어 진단』(연구책임 이상신)이 정책 제안 절에서
   스스로 밝혔다 — "현재 평가의 기준으로는 내용적인 측면에 대한 평가가
   이루어지기 어렵다."
2. **기존 맞춤법 검사기가 문장 차원 오류를 10~17%만 잡는다.** 김영일·김완섭(2021)
   『문화와융합』 43(3)이 검사기 4종 × 문장 차원 30문항을 실측했다. 표기 차원은
   21~28/30을 잡지만 문장 차원은 3~5/30이다.
3. **성인 연구자의 학술 텍스트용 루브릭이 없다.** 국립국어원 기준안은 논증적 글,
   AI Hub는 초·중·고 에세이, KoLLA·TOPIK은 L2 학습자용이다.

이 스킬은 그 사이 층 — **문단 논리·논증 구조·학술 문체** — 를 다룬다.

## 1. 설계의 근간 — 왜 3층인가

Kim, Taeryeong(2026) *Frontiers in Education* 11이 평정자 42명, 204,894 관측치로
**루브릭 명세성에 따른 채점 신뢰도**를 측정했다.

| 수준 | 정의 | 평균 QWK |
|---|---|---|
| Level 1 규칙 기반 | 검증 가능·결정적 조건 | **.915** |
| Level 2 준거 참조 | 명시적 기술어 + 판단 필요 | **.597** |
| Level 3 판단 기반 | 개방형 인상 평가 | **.528** |

준거별로는 문법 정확성 .905인 반면 **문장 연결성 .483, 어휘 적절성 .432**다.
**응집성과 문체는 인간 평정자끼리도 일치하지 않는다.**

같은 연구가 하나 더 보고한다 — **준거 난도 범위(3.09 logits)가 평정자 엄격도
범위(1.003 logits)의 약 3배**다.

여기서 두 가지 설계 원칙이 나온다.

> **원칙 1. 층마다 판정 권한이 다르다.**
> 신뢰도 .5짜리 판단을 .9짜리 판정과 같은 형식으로 내놓으면, 사용자는 둘을
> 구별할 수 없다. L3에서 "이것이 최적입니다"라고 말하는 것은 측정 가능한
> 근거를 넘어선 주장이다.

> **원칙 2. 리뷰어를 늘리는 것보다 준거를 명세화하는 것이 3배 중요하다.**
> 따라서 이 스킬은 리뷰어 수를 늘리지 않는다. 대신 매뉴얼의 각 항목에
> 출처와 판정 조건을 붙인다.

## 2. 3층 구조

| 층 | 대상 | 판정 방식 | 리뷰어 | 매뉴얼 |
|---|---|---|---|---|
| **L1** | 문장 규칙·표기·수치 정합 | **결정적 판정.** 규칙 위반은 위반이다 | 불필요 | `manual/L1_sentence_rules.md`, `L1_paragraph_rules.md`, `L1_quantitative_integrity.md` |
| **L2** | 논증 구조·섹션 간 정합 | **패널 다수결.** 과반 지적 시 확정 | 2–3인 | `manual/L2_argument_rubric.md`, `L2_structural_integrity.md` |
| **L3** | 문체·응집성·어휘 선택 | **판정하지 않는다.** 선택지 제시 + 저자 결정 | 2–3인 | `manual/L3_style_cohesion.md` |

### L1 — 결정적 판정

R1~R20의 문장 규칙과 단락 수치 규범은 조건이 명시되어 있어 참·거짓을 다툴 수
있다. 리뷰어 합의가 필요 없다. 검출되면 지적하고 교정형을 제시한다.

단, **규칙마다 출처를 함께 표시한다.** 출처 없는 규칙은 매뉴얼에 없다(§5 참조).

### L2 — 패널 다수결

논거 개수, 반론 대응 유형, 문단-주제 연결처럼 **명시적 기술어는 있으나 적용에
판단이 개입하는** 항목이다. 리뷰어 2–3인이 독립 판단하고 과반이 지적하면 확정한다.
1인만 지적하면 `[소수 의견]`으로 표시하되 확정하지 않는다.

### L3 — 판정 금지

문체·응집성·어휘 선택은 **Agent J가 최적안을 고르지 않는다.** 후보를 나열하고
각각의 트레이드오프를 적되, "이것이 최적"이라고 말하지 않는다. 사용자가 고른다.

이것이 원본 `meta-proofreading`과의 가장 큰 차이다. 그 스킬은 Agent J가 전 층위에서
optimal을 선정한다. 한국어판은 **L3에서 optimal 필드를 비운다.**

## 4. 반드시 피해야 할 세 가지 과잉 규범

조사에서 확인된, **널리 믿기지만 근거가 없거나 반대인** 항목이다.

### 4-1. "접속어를 늘리면 글이 좋아진다" — 반박됨

| 출처 | 내용 |
|---|---|
| 정희모(2019) | "텍스트 질과 결속성 장치는 통계적으로 유의미한 상관관계가 없거나 아니면 부적관계로 드러났다" |
| 박혜진·이미혜(2017) | 대용(이·그·이러한)은 응집성과 **음의 상관**. 접속 중 상술(즉·다시 말해)만 양의 상관 |
| 이수곤(2021) | 접속사의 **기본값은 미사용** |
| 정언학(2014) | "한 단락 4~6문장에 접속어 3~4개는 문장 연결을 매우 어색하게 만든다" |

→ **"전환어가 없으니 넣으라"는 지적을 L1·L2에서 하지 않는다.** L3에서 선택지로만
제시하고, 제시할 때 위 상충 근거를 함께 밝힌다.

### 4-2. "개조식은 일제 잔재이므로 폐지" — 국가 지침에 근거 없음

『쉬운 공문서 쓰기 길잡이』(2022) p.49: "**줄글보다는 개조식으로 작성하여** 글의
전체 내용을 한눈에 쉽게 파악할 수 있도록 한다." 국립국어원은 일제 기원 확인을
거부했다(온라인가나다 qna_seq=320204).

→ 대신 명문 근거가 있는 것만 쓴다: ① 개조식은 요약·게시 층위에 한정
② **명사 나열식 문장 금지**(2022 길잡이 p.49) ③ 규범적 내용은 완전한 서술문으로.

### 4-3. "이중피동은 무조건 오류" — 과잉

어문 규범에 조항이 없고 국립국어원 답변도 "부자연스러울 가능성이 높다"는 완화된
표현을 쓴다. **판정 규칙**으로만 적용한다 — ① 어기가 이미 피동사인가
② 피동 3장치(접미사 `-이/히/리/기-` / `-어지다` / `-게 되다`) 중 2개 이상 중첩인가.
법제처는 **무생물 주어의 피동문을 명시적으로 허용**한다.

## 5. 3개 모드

| 모드 | 대상 | 실행 층 |
|---|---|---|
| **1. 원고 전체** | 초고 전문 | L1 전량 + L2 전량 + L3 표본 |
| **2. 섹션** | 한 절·장 | L1 + L2(섹션 내부만) + L3 |
| **3. 단락** | 한 단락 + 문장 단위 | L1 + L3. **L2 섹션 간 정합은 판정 불가 — 그렇다고 말한다** |

Mode 3는 **패널 심의가 필요할 때만** 쓴다. 단락 하나를 원칙 기준으로 진단하고
대안 3안을 받는 일반 경로는 `meta-rewriting-korean`이고, 거기가 더 싸고 빠르다.
이 스킬의 Mode 3는 리뷰어 합의가 값어치를 하는 경우 — 지적이 다툼의 여지가
있거나, 저자가 독립 시선 여러 개를 원할 때 — 를 위해 남겨둔 것이다.

Mode 3에서 `L2_structural_integrity.md`의 섹션 간 판정(질문 사슬, 초록↔본문)은
**양쪽 섹션이 다 있어야 가능하다.** 못 한다고 말하지, 통과한 것처럼 굴지 않는다.

## 6. 실행 절차

```
PHASE 1  입력 파싱 + 지식 자원 탐색
         → knowledge/input_handler.md, distribution_strategy.md
PHASE 2  L1 결정적 검출 (리뷰어 없이 오케스트레이터가 직접)
         → manual/L1_*.md 전량 로드
PHASE 3  L2 패널 심의 (리뷰어 2–3인 병렬)
         → agents/agent_reviewer.md, manual/L2_*.md
PHASE 4  L3 선택지 생성 (리뷰어 2–3인 병렬, 판정 없음)
         → manual/L3_style_cohesion.md
PHASE 5  Agent J 판정 — **L1·L2만.** L3는 ranking만 정렬
         → agents/agent_j.md
PHASE 6  출력 + 저자 결정 대기
```

### PHASE 2가 먼저인 이유

L1은 결정적이라 패널이 필요 없고, L1에서 걸린 문장은 L3 후보 생성 대상에서
빠진다. 곧 교정될 문장의 문체 대안을 만드는 것은 낭비다
(`meta-writing-mapping`·`meta-rewriting-korean`의 "전역에서 국소로"와 같은 논리).

### 병렬 실행

리뷰어는 **한 응답에서 Agent tool 여러 번 호출**로 동시에 띄운다. 리뷰어 수는
2–3인을 기본으로 하며 **늘리지 않는다** — §1 원칙 2.

## 7. 출력 규약

### 층별 표기 — 반드시 구별되게

```
[L1 · 확정]   규칙 위반. 교정형 제시. 근거 = 출처명 + 쪽수
[L2 · 확정]   리뷰어 과반 지적. 준거명 + 배점
[L2 · 소수]   1인 지적. 확정 아님
[L3 · 선택]   후보 N개. 최적 없음. 저자 결정
[판정 불가]   모드 제약으로 볼 수 없음
```

**L3 출력에 "최적안", "추천", "권장"이라는 말을 쓰지 않는다.** 각 후보에
트레이드오프만 붙인다.

### 고정 삽입 고지

> 이 결과는 **층별로 신뢰도가 다르다.** L1은 명문 규칙 대조이고, L2는 리뷰어
> 합의이며, L3는 선택지 제시다. L3 항목에 최적안이 없는 것은 누락이 아니라
> 설계다 — 문체·응집성은 인간 평정자 간 일치도가 .43~.48 수준이며(Kim 2026),
> 그 층위에서 단일 정답을 제시하는 것은 측정 가능한 근거를 넘어선다.
> 인용·수치의 진위는 검증되지 않았다. 주장 단위 검토는 저자의 몫이다.

## 8. 다른 스킬과의 경계

| 하는 일 | 스킬 |
|---|---|
| 섹션·단락 **배치 설계** (문장 이전) | `meta-writing-mapping` |
| 근거 수집 + **문장 생성** | `meta-writing` |
| 한국어 **단락 하나** 리뷰·리라이팅 (3안, 개인 문체 포함) | `meta-rewriting-korean` |
| **한국어 원고 심의 교정** | **이 스킬** |
| 영문 원고 심의 교정 | `meta-proofreading` |
| 표현이 실제 논문에 쓰이는지 실증 | `meta-proofreading-evidence` |

`meta-rewriting-korean`의 C안과 겹치는 것처럼 보이지만 권위가 다르다. 그쪽의
Blueprint는 **저자 본인의 발간물**에서 추출한 기술적 규범이고, 이 스킬은 **공표된
규범**을 따른다. 둘이 충돌하면 — 예컨대 Blueprint는 "따라서 8+회/편"인데 이 스킬은
"접속어 기본값 미사용"인데 — **충돌 자체를 사용자에게 보고하고 판정하지 않는다.**
