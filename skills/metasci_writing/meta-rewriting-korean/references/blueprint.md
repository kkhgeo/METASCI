## Dimension 1: 어조 & 격식 (Tone & Stance)

### 규칙

#### 1.1 기본 문체: 해라체 (격식 평서형)
- 전체 문서에서 해라체(~이다/~있다/~한다)를 일관되게 사용한다.
- 합쇼체(~입니다/~합니다)는 본문에서 사용하지 않는다. 유일한 예외: KEI2022의 서두 안내문 1회 "~밝힙니다."
- 1인칭 '나'는 절대 사용하지 않는다. '우리' 또는 '우리나라'는 간헐적으로 사용 가능하다.
- 주어는 비인칭(제도/법/계획/평가) 위주이다.

#### 1.2 종결어미 체계 (빈도 순)
| 종결어미 | 기능 | 빈도 | 사용 맥락 |
|---------|------|------|----------|
| **~이다/~다** | 평서 단정 | 매우 높음 | 정의, 개념 진술, 사실 기술 |
| **~있다** | 존재/진행 | 높음 | 현황 보고, 동향 기술 (~하고 있다, ~되어 있다) |
| **~한다/~된다** | 평서 서술 | 높음 | 기능 설명, 제도 운영 기술 |
| **~해야 한다** | 당위 | 높음(후반부 집중) | 과제 제시, 제언, 결론 |
| **~필요하다** | 필요성 | 높음(후반부) | ~할 필요가 있다, ~이 필요하다 |
| **~(이) 요구된다** | 필요성(피동) | 중간 | 개선 필요성, 당위적 요구 |
| **~것으로 예상/전망/추정된다** | 추정 | 중간(서론) | 전망, 추세 판단 |
| **~고자 한다** | 의도 | 낮음 | 연구/리뷰 목적 진술 |
| **~수밖에 없다** | 불가피성 | 낮음 | 강한 경고 |

#### 1.3 객관적 → 당위적 전환 구조 (공통 패턴)
- 서론/개요: 객관적 배경 기술 (~이다, ~있다) — 당위 표현 최소
- 현황: 사실/데이터 보고 (~이다, ~있다) — 당위 표현 0건
- 역할/담론 분석: 분석+논증 (~있다, ~한다) — 당위 표현 점진 증가
- 과제/전략: 제안+당위 (~해야 한다, ~필요가 있다) — 당위 표현 급증
- 맺음말: 종합+강조 (~해야 한다, ~요구된다) — 당위 표현 최대

#### 1.4 헤징 표현 목록 (강도 순)
| 강도 | 표현 | 실제 사용례 |
|------|------|-----------|
| **강함 (단정)** | ~이 분명하다 | "지속가능성 문제에 직면하고 있음이 분명하다" |
| **강함 (당위)** | ~해야 한다 | "다원주의 거버넌스를 구축해야 한다" |
| **강함 (당위)** | ~적용되어야 한다 | "전략적 계획과정으로 적용되어야 한다" |
| **강함 (불가피)** | ~수밖에 없다 | "자원고갈을 마주할 수밖에 없다" |
| **중강 (필요)** | ~이 필요하다 | "패러다임 전환과 전략의 모색이 필요하다" |
| **중강 (필요)** | ~할 필요가 있다 | "평가지표를 개발할 필요가 있다" |
| **중강 (필요)** | ~(이) 요구된다 | "실효적인 대안평가가 요구된다" |
| **중간 (가능)** | ~할 수 있다 | "통합물관리 정책과 연계할 수 있다" |
| **중간 (추정)** | ~것으로 예상/전망/추정된다 | "전환점이 될 것으로 예상된다" |
| **중간 (인식)** | ~로 이해/인식되고 있다 | "'의사결정 지원 도구'로 이해된다" |
| **중간 (의도)** | ~고자 한다 | "전략을 제안하고자 한다" |
| **약함 (양보)** | ~가능하겠지만 | "다양한 논의가 가능하겠지만" |
| **약함 (근사)** | 약, ~여 | "연평균 약 100여건" |

#### 1.5 당위 표현 (강도별)
| 표현 | 강도 | 사용 맥락 |
|------|------|----------|
| ~해야 한다 | 최강 | 핵심 제언, 과제 제시 |
| ~적용되어야 한다 | 최강(피동 당위) | 제도 운영 방향 |
| ~(이) 요구된다 | 강 | 개선 필요성 |
| ~할 필요가 있다 | 중강 | 과제 제시(약간 완화) |
| ~이 필요하다 | 중강 | 방향 제시 |
| ~필요한 시점이다 | 중강+시간 | 전환점 강조 |

### 실제 사용 예시
1. "따라서 전략환경영향평가를 통해 통합물관리 목표에 부합하는 자연친화적이며 지속가능한 하천관리를 계획**해야 한다**." (KimKH2020 맺음말)
2. "우리는 기후변화가 가속화되는 국제적 위기 상황에서 지속가능성 문제에 직면하고 있**음이 분명하다**." (KEI2022 서론/맺음말 — 수미상관)
3. "이에 금회 리뷰를 통해 지금까지 논의·연구된 환경평가의 한계와 미래의 발전 방향을 짚어보고, 국내 환경평가의 중장기 연구과제를 포함한 전략을 제안하**고자 한다**." (KEI2022 서론)

### 재사용 템플릿
```
[Tone-T1] "[주제어]는/은 [목적/기능] 아래 [행위]을/를 도모하는 [도구/수단]이다."
[Tone-T2] "우리는 [위기/상황]이 가속화되는 [맥락] 상황에서 [문제]에 직면하고 있음이 분명하다."
[Tone-T3] "이에 [본 연구/리뷰]를 통해 [분석 대상]의 [한계/과제]와 [방향]을 짚어보고, [제안 내용]을 제안하고자 한다."
[Tone-T4] "[대상]에 대한 [평가/제도]는 [프레임워크] 측면에서 [기능A]을 확인하고, [기능B]를 실현할 수 있도록 대안을 제시하는 [과정]으로 적용되어야 한다."

```

## Dimension 2: 문장 구조 (Sentence Architecture)

### 규칙

#### 2.1 평균 문장 길이
- KimKH2020: 평균 ~70자 (범위: 40-130자)
- KEI2022: 평균 ~50자 (범위: 20-110자)
- 종합: **40~80자가 주력 구간**, 100자 이상 장문도 빈번하게 사용
- 장문은 주로 법률 정의 인용, 열거형 제안, 종합 진술에서 등장

#### 2.2 문장 구조 유형 비율
| 구조 유형 | 비율 | 특징 |
|----------|------|------|
| **Complex (복합문)** | ~55% | 가장 우세. 종속절+주절 구조 |
| **Compound-Complex** | ~20% | 나열+종속 결합. 정의·설명문에 빈출 |
| **Compound (중문)** | ~15% | ~하고, ~하며 연결. 병렬 기술에 사용 |
| **Simple (단문)** | ~10% | 핵심 주장, 요약 진술에 전략적 사용 |

#### 2.3 능동/피동 비율
- 전체: 능동 55~60% : 피동 40~45%
- 서론/개요: 능동 60:피동 40 (배경 기술 → 능동 우세)
- 현황: 능동 50:피동 50 (제도 기술 → 피동 증가)
- 역할/담론: 능동 55:피동 45
- 과제/전략: 능동 60~65:피동 35~40 (당위적 제안 → 능동 증가)
- 맺음말: 능동 55~60:피동 40~45

**피동 기능별 분류 (주요 패턴)**:
- 제도 기술용: ~포함된다, ~수립되었다, ~운영되고 있다
- 문제 지적용: ~활용되지 못하고, ~인공화되었다
- 당위적 피동: ~요구된다, ~적용되어야 한다, ~예상된다

#### 2.4 연결어미 목록 (빈도 순)
| 연결어미 | 기능 | 빈도 | 예시 |
|---------|------|------|------|
| **~하여/~하여서** | 원인/순서/수단 | 매우 높음 | "조사·분석**하여** 종합계획 수립" |
| **~하며/~으며** | 병행/동시 | 높음 | "규제하지 못하는 실정이**며**" |
| **~하고** | 나열/첨가 | 높음 | "제도를 도입**하고** 제정하여" |
| **~면서** | 동시 진행 | 중간 | "경험을 축적하**면서** 발전을 이루었고" |
| **~함으로써** | 수단/방법 | 중간 | "성과를 증명**함으로써**" |
| **~(으)므로** | 이유/근거 | 중간 | "법제화하고 있**으므로**" |
| **~(으)므로/~때문에** | 원인 | 중간 | "소관으로 남겨져 **때문에**" |
| **~지만** | 대조/양보 | 중간 | "다가오고 있**지만** 달성이 어려울" |
| **~더라도** | 양보 | 낮음 | "확대되**더라도** 전환적 사고 없이는" |
| **~도록** | 목적/결과 | 중간 | "도출되**도록** 투명성을 확보해야" |
| **~하되** | 조건/양보 | 낮음 | "반영을 기본으로 **하되** 환경현황을 고려하여" |

#### 2.5 명사화 패턴
| 패턴 | 기능 | 예시 |
|------|------|------|
| **~성** | 속성 명사화 | 적정성, 타당성, 공정성, 신뢰성, 투명성, 합법성, 합리성, 불확실성, 지속가능성, 실효성, 포괄성, 전략성, 통합성 |
| **~화** | 과정/결과 명사화 | 일원화, 인공화, 고도화, 내실화, 활성화, 가속화 |
| **~적** | 형용성 접미 | 자연친화적, 복합적, 종합적, 체계적, 획일적, 실효적, 점진적, 실천적, 건설적, 포괄적, 목표 지향적 |
| **~(으)ㅁ** | 동사→명사 | "직면하고 있**음**이 분명하다" |
| **~바** | 형식명사 | "연구를 수행한 **바** 있다" |
| **~데** | 형식명사 | "도모하는 **데** 많은 성과" |

### 실제 사용 예시
1. "하천기본계획은 「하천법」에 의거 유역의 강우, 하천의 유량, 수질 및 생태, 하천의 이용현황 등 하천의 치수, 이수, 환경에 관한 제반 사항을 조사·분석**하여** 하천의 종합적인 정비와 하천의 이용 및 자연친화적 관리 등을 위한 종합계획 수립" (120자, Complex, 다중 나열)
2. "지난 50여 년간 환경평가는 국토환경의 친환경적 개발 및 지속가능한 발전을 도모하는 데 많은 성과와 경험을 축적하**면서** 제도적으로 점진적인 발전을 이루었**고**, 환경평가에 대한 사회적 관심과 이해는 꾸준히 증가하고 있다." (80자, Compound-Complex)
3. "환경평가의 미래역량은 절차 및 과정이 아닌 문제 해결에 기여하기 위한 실질적인 성과에 있다." (35자, Simple — 핵심 주장의 전략적 단문)

### 재사용 템플릿
```
[Arch-T1] "[제도명]은 「[법명]」에 의거/에 따라 [범위]에 관한 제반 사항을 조사·분석하여 [목적]을 위한 [계획유형]이다."
[Arch-T2] "지난 [기간] [주제어]는/은 [성과]를 축적하면서 [방향]으로 점진적인 발전을 이루었고, [관련 사항]은/는 꾸준히 [변화]하고 있다."
[Arch-T3] "[주제어]의 [핵심역량]은/는 [비핵심]이/가 아닌 [핵심]에 기여하기 위한 [가치]에 있다."
[Arch-T4] "[주제어]는/은 [대상A]을/를 확인하고, [대상B]를 예상하여 [목적]을/를 마련하기 위한 수단으로 활용되고 있다."

```

## Dimension 3: 논리 흐름 (Logical Flow)

### 규칙

#### 3.1 거시 논증 구조 (양 문서 공통 패턴)

**KimKH2020 구조**: 개요 → 현황 → 역할 → 과제 → 맺음말
```
정의·법적 근거 설정 → 통계·현황 진단 → 이상적 역할 논증(3 pillars) → 개선 과제 나열 → 종합 제언
```

**KEI2022 구조**: 서론 → 미래 담론 → 발전 전략 → 맺음말
```
배경·전환점 인식·목적 → 담론 정리(4 themes) → 전략 제안 → 종합 강조
```

**공통 거시 패턴**: `배경/정의 → 현황 진단/문제 분석 → 역할/방향 논증 → 과제/전략 제안 → 종합 제언`

#### 3.2 단락 기능 태그 목록 + 빈도 (양 문서 합산)

| Function Tag | 빈도 | 사용 맥락 |
|-------------|------|----------|
| **Policy-Background** | 높음 | 법적·제도적 배경 설명 (서론/개요, 역할 도입) |
| **Policy-Definition / Concept-Definition** | 높음 | 제도·개념의 법적 정의 제시 |
| **Purpose / Purpose-Statement** | 중간 | 연구/리뷰 목적 진술 |
| **Statistics / Current-Status** | 중간 | 통계 데이터 제시, 현황 보고 |
| **Problem-Identification / Gap-Signal** | 중간 | 현행 문제점·한계 지적 |
| **Role-Definition / Role-Elaboration** | 중간 | 이상적 역할 정의 및 상세화 |
| **Improvement-Proposal** | 높음 | 구체적 개선 과제 제시 (첫째~넷째) |
| **Summary / Synthesis** | 중간 | 섹션 또는 전체 종합 |
| **Future-Direction** | 중간 | 향후 방향 및 전망 |
| **Discourse-Framing** | 중간 | 담론 프레이밍, 학술 논의 구조 설정 |
| **Review-Finding** | 낮음 | 검토 결과 요약 |
| **Section-Transition** | 낮음 | 섹션 전환 브릿지 |

#### 3.3 단락간 논리 관계 패턴 (빈도 순)

| 관계 | 빈도 | 시그널 | 기능 |
|------|------|--------|------|
| **Continuation** | 최다 (~30%) | (무표지), "한편", "또한" | 정보 축적, 보충적 서술 |
| **Cause-Effect** | 높음 (~20%) | "따라서", "하므로", "이에" | 인과 추론, 결론 도출 |
| **Specification** | 높음 (~15%) | "즉", "여기서" | 일반→구체 상세화 |
| **Contrast** | 중간 (~12%) | "하지만", "그러나" | 대비, 문제 제기, 새 하위주제 도입 |
| **Sequence** | 중간 (~10%) | "첫째/둘째/셋째/넷째" | 과제 순서 나열 |
| **Concession** | 중간 (~8%) | "하지만", "~에도 불구하고" | 양보+반전 |
| **Elaboration** | 중간 (~8%) | "나아가", "뿐만 아니라" | 심화·확장 |
| **Problem-Solution** | 낮음 | "이러한 관점에서" | 문제 인식 → 해결 방안 전환 |

#### 3.4 전형적 단락 내부 구조 (Intra-Paragraph)
- 가장 빈번한 패턴: **Topic → Elaboration → Conclusion** (3-sentence pattern)
- 매 문단의 첫 문장은 100% Topic sentence 역할
- 주요 문장 관계: Elaboration (~25%), Cause-Effect (~20%), Addition (~18%)
- 열거형 구조(①②③)는 역할(SEC03) 및 과제(SEC04) 섹션에서 빈출

#### 3.5 열거형 제안 구조 (특징적 패턴)

**서수사 나열 (SEC04/과제)**:
```
첫째, [과제 1] ~할 필요가 있다.
둘째, [과제 2] ~해야 한다.
셋째, [과제 3] ~수행할 필요가 있다.
넷째, [과제 4] ~검토해야 한다.
한편 [부가 과제] ~가 요구된다.
```

**원문자 나열 (SEC03/역할)**:
```
즉 [제도]는 ① [기능1]을 갖는다.
뿐만 아니라 ② [기능2] 역할을 수행하며,
③ [기능3]에 제공할 수 있다.
```

**글머리표/번호 나열 (KEI2022/전략)**:
```
미래 방향: ● [방향1], ● [방향2], ● [방향3]...
4대 핵심전략: 1) [전략1], 2) [전략2], 3) [전략3], 4) [전략4]
```

#### 3.6 수미상관 구조 (KEI2022 특징)
- 서론(P2)의 "지속가능성 문제에 직면하고 있음이 분명하다"가 맺음말(P35) 첫 문장에서 거의 동일하게 반복
- 핵심 주장을 서론과 맺음말에서 변주 반복하여 문서 전체를 프레이밍

### 실제 사용 예시
1. **3-pillar 논증 구조** (KimKH2020 SEC03): (1) 통합물관리 → (2) 자연친화적 하천관리 → (3) 전략적 계획과정. 각 하위 논증은 동일 내부 패턴: Background → Gap → Role-Definition → Elaboration
2. **순서 나열 과제 구조** (KimKH2020 SEC04): "첫째, 평가지표를 개발할 필요가 있다. → 둘째, 하천환경정보지도로 구축해야 한다. → 셋째, 공간관리계획 수립을 수행할 필요가 있다. → 넷째, 치수목표와 홍수방어수단을 체계적으로 검토해야한다."
3. **변증법적 담론 구조** (KEI2022 SEC2.1): Revolution(혁신주의) 주장 → Evolution(진화주의) 반론 → 종합 → "전환적 사고 필요"로 수렴

### 재사용 템플릿
```
[Logic-T1] 거시구조: "배경/정의 → 현황/문제 분석 → 역할/방향 논증 → 과제/전략 제안 → 종합 제언"
[Logic-T2] 하위논증: "[정책배경] → 하지만 [문제점] → 따라서 [역할 정의] → 나아가 [역할 확장]"
[Logic-T3] 순서형 과제: "첫째, [과제A]할 필요가 있다. 둘째, [과제B]해야 한다. 셋째, [과제C]할 필요가 있다."
[Logic-T4] 원문자 기능열거: "즉 [제도]는 ① [기능1]을 갖는다. ② [기능2] 역할을 수행하며, ③ [기능3]에 제공할 수 있다."
[Logic-T5] 수미상관: 서론 핵심 문장 → 맺음말에서 변주 반복
```

#### 4.2 위치 패턴
- **문두 전환어**: 따라서, 즉, 나아가, 하지만, 한편, 이에, 또한, 예를 들어 등 — 가장 빈번
- **절 연결**: ~하며, ~하고, ~이므로, ~때문에, ~면서 — 복합문 내부
- **절 내부**: ~에 따라, ~에 의거, ~와 달리, ~을 통해 — 전치사적 기능

#### 4.3 섹션별 전환어 변화 패턴 (공통)
- 서론/개요: 따라서, 즉, 이러한 관점에서 (인과·부연 중심)
- 현황: 한편, 따라서, 즉, ~에 따르면 (화제전환+데이터 근거)
- 역할/담론: 하지만, 즉, 이에, 나아가, 예를 들어 (대조·심화 중심)
- 과제/전략: 첫째~넷째, 한편, 결과적으로 (순서+종합)
- 맺음말: 따라서, 나아가, 앞으로, 즉, 이를 위해 (전망·수단 중심)

### 실제 사용 예시
1. "**따라서** 하천기본계획에 대한 전략환경영향평가의 목적은 환경의 보전 측면에서 이·치수계획의 적정성을 확인하여 지속가능한 하천관리를 도모하는 데 있다." (인과/결론)
2. "**하지만** 전략환경영향평가가 계획과정의 전략적 도구로 활용되지 못하고, 제도적 승인 절차로 운영되는 경우가 많다." (대조/문제 제기)
3. "**나아가** 하천기본계획에 대한 전략환경영향평가는 하천의 지역(중소유역) 물거버넌스의 활성화를 돕고, 지방하천의 생태 및 환경 정보를 유역물관리위원회 등 대권역 단위의 관리체제에 상향식으로 제공한다." (심화/확장)

## Dimension 6: 인용 & 근거 (Citation & Evidence)

### 규칙

#### 6.1 법률 인용 방식
| 패턴 | 형식 | 예시 |
|------|------|------|
| **법률명 기본** | 「법률명」 (꺾쇠 필수) | 「환경영향평가법」, 「하천법」, 「물관리기본법」 |
| **법률+근거** | 「법명」에 의거/에 따라 | "「하천법」에 의거 유역의 강우..." |
| **법률+정의** | 「법명」에서는 ~을 "..."으로 규정하여 시행하고 있다 | "「환경영향평가법」에서는 전략환경영향평가를 '환경에 영향을 미치는...'으로 규정하여 시행하고 있다." |
| **법률+조항** | 「법명」, 제N조 및 동법 시행령 N조 | "「하천법」, 제25조 및 동법 시행령 24조 등의 규정에서는" |
| **규정명** | 「규정명」에서 제시한 | "「전략환경영향평가서의 작성방법에 관한 규정」에서 제시한" |
| **법률 조항** | 법명 제N장에서는 | "현행 하천법 제6장에서는 하천의 보전·관리에 관한 규정을 두고 있으며" |

**핵심 규칙**: 법률명은 반드시 꺾쇠(「」)로 감싸야 한다. 따옴표(' ') 사용 불가.

#### 6.2 학술 인용 방식
| 패턴 | 형식 | 예시 |
|------|------|------|
| **비통합형 (영문)** | (저자, 연도) | "(UNEP, 2019)", "(Retief et al. 2016)" |
| **비통합형 복수** | (저자; 저자, 연도) | "(Hacking, 2018; Partidário and Verheem, 2019)" |
| **통합형 (영문)** | 저자(연도)는/은 ~를 | "Bidstrup and Hansen(2014)은 ...를 보고한바 있다" |
| **통합형 (국문)** | 저자 외(연도)는 ~를 | "유헌석 외(2022)는 '환경평가제도의 목표 확대'를 ...제안하고 있다" |
| **간접 인용** | ~다고 지적하면서/지적하고 있다 | "Bond and Dusik(2020)는 ...어렵다고 지적하면서" |
| **메타적 인용** | ~주장을 인용하자면 | "다시금 혁신주의 주장을 인용하자면, Partidario(2020)는" |
| **비유적 인용** | 저자(연도)의 미래 비전처럼 | "Therivel(2020)의 미래 비전처럼" |

**통합형과 비통합형을 혼용**하는 것이 특징이다. 문헌의 학술적 기여를 강조할 때 통합형, 근거 보강에는 비통합형을 사용한다.

#### 6.3 통계/데이터 인용 방식
| 패턴 | 형식 | 예시 |
|------|------|------|
| **기관 데이터** | 기관명(기관, 연도)에 따르면 | "한국하천일람(국토교통부, 2018)에 따르면" |
| **수치 병기** | N개소(N,NNNkm) | "93개소(3,297km)와 4,712개소(26,933km)" |
| **백분율** | N.N% | "국가하천이 95.5%이며 지방하천은 86.29%" |
| **총량 도달** | 총 연장 Nkm에 이른다 | "총 연장 30,268km에 이른다" |
| **연평균** | 연평균 약 N여건 | "연평균 약 100여건" |
| **기간+건수** | 최근(N년간)의 ~건수는 총 N건 | "최근(9년간)의 협의 건수는 총 943건" |
| **기간 표현** | 지난 N여 년간 | "지난 50여 년간" |

#### 6.4 표/그림/각주 사용 패턴
| 요소 | 방식 | 예시 |
|------|------|------|
| **본문 참조** | (표 N), (그림 N), (표 N 참조), (그림 N 참조) | "(그림 2).", "(표 3 참고)" |
| **표/그림 출처** | 자료: 기관명(연도) / 자료: 저자작성 | "자료: 국토교통부(2018)" |
| **가공 출처** | ~를 토대로 저자(연도)가 작성 | "Bidstrup and Hansen(2014)을 토대로 김경호 외(2018)가 작성" |
| **각주** | 상첨자 번호 + 페이지 하단 | "환경평가^1)는", "메가트렌드^2)" |
| **영문 약어** | 한글명(영문약어) | "지속가능발전목표(SDGs)", "탄소중립(C-Neutrality)" |

**시각 자료 밀도**: KimKH2020은 6그림+5표(11 visual, ~1.6p당 1개), KEI2022는 3그림+4표. 정책 리뷰 특성상 시각 자료 밀도가 높다.

#### 6.5 각주 사용 패턴
- 주로 법적 정의, 용어 설명, 부가 데이터에 사용
- KimKH2020: 18개 각주 (법률 인용 집중)
- 각주 번호 형식: 1), 2), 3)...

### 실제 사용 예시
1. "「환경영향평가법」에서는 전략환경영향평가를 '환경에 영향을 미치는 상위계획을 수립할 때에 환경보전계획과의 부합 여부 확인 및 대안의 설정·분석 등을 통하여 환경적 측면에서 계획의 적정성 및 입지의 타당성을 검토하여 국토의 지속가능한 발전을 도모하는 것'으로 규정하여 시행하고 있다." (법률 직접 인용)
2. "한국하천일람(국토교통부, 2018)에 따르면 우리나라에는 국가 및 지방하천이 93개소(3,297km)와 4,712개소(26,933km) 각각 분포하며 이는 총 연장 30,268km에 이른다." (통계 인용)
3. "최근 Banhalmi-Zakar et al.(2018)은 21세기 환경위기의 상황에서 환경평가의 한계 극복을 위해 점진적 또는 근본적인 전환의 필요성에 대한 화두를 제안하였고 이는 IAIA19에서 논의된 바 있다." (통합형 학술 인용)

### 재사용 템플릿

## Dimension 7: Anti-AI 필터 (참조용 요약)

> 상세 패턴은 `korean-anti-ai-patterns.md`에서 참조할 것.

### 7.1 한국어 AI 글쓰기 패턴 탐지 기준 요약

AI 생성 한국어 텍스트의 전형적 패턴과 나의 글의 자연스러운 특성을 대조한다.

### 7.2 나의 글이 AI 패턴과 다른 핵심 특성

| AI 전형 패턴 | 나의 글의 자연스러운 특성 |
|-------------|----------------------|
| **균일한 문장 길이** | 20자 단문~130자 장문의 넓은 범위. 핵심 주장은 전략적 단문, 정의/나열은 장문 |
| **기계적 구조 반복** | 섹션별로 전환어·종결어미·헤징 밀도가 유기적으로 변화 (Dim.1의 객관→당위 전환) |
| **과도한 헤지/무표지 연결** | 따라서/하지만/즉/나아가 등 명확한 논리 시그널 사용. 헤징은 섹션에 따라 밀도 변화 |
| **피상적 나열 (3-item lists)** | 첫째~넷째 서수사 + ①②③④ 원문자를 조합한 다층적 나열. 각 항목에 근거 동반 |
| **일관된 감정/어조** | 객관적 배경 → 분석적 담론 → 당위적 제안 → 강조적 종합으로 점진적 어조 전환 |
| **추상적 서술** | 법률 조항·통계 수치·시각 자료(그림/표)를 밀도 높게 통합. 구체적 정책 맥락에 근거 |
| **~합니다 종결** | 해라체(~이다/~있다/~한다) 일관 사용. 합쇼체 본문 사용 없음 |
| **1인칭 '나' 사용** | '우리'/'우리나라' 간헐 사용 + 비인칭 주어 위주 |
| **영문 표현 직역** | 한자어 75%의 정책 레지스터. 외래어는 한글(영문약어) 병기로 자연스럽게 통합 |
| **수미 단절** | 서론과 맺음말의 수미상관(首尾相關) 구조로 핵심 주장 반복 |

### 7.3 자연스러움 유지를 위한 체크리스트
- [ ] 문장 길이 변이: 20자~130자 범위 내에서 자연스러운 변화가 있는가?
- [ ] 섹션별 어조 전환: 배경(객관) → 분석(중립) → 제안(당위) 순서가 지켜지는가?
- [ ] 전환어 다양성: 동일 전환어 연속 반복 없이 따라서/즉/나아가/하지만 등을 교차 사용하는가?
- [ ] 당위 표현 분포: 서론에서는 최소, 과제/맺음말에서 집중되는가?
- [ ] 피동 기능 분화: 기술용 피동, 문제 지적용 피동, 당위적 피동을 구분하여 사용하는가?
- [ ] 구체적 근거: 법률 조항, 통계 수치, 학술 문헌이 적절히 결합되어 있는가?
- [ ] 한자어/고유어 균형: 정책 용어는 한자어, 서술·부사는 고유어(꾸준히, 면밀히 등) 혼용하는가?

## 종합: 나의 글쓰기 지문 (Style Fingerprint)

1. **격식 해라체 일관 사용**: ~이다/~있다/~한다 체계를 전체 문서에서 유지하며, 합쇼체나 1인칭 '나'는 사용하지 않는다. 비인칭(제도/법/계획) 주어가 지배적이고, '우리나라'를 간헐적으로 사용한다.

2. **객관에서 당위로의 점진적 어조 전환**: 서론/개요에서는 사실과 배경을 객관적으로 기술하고, 중반부에서 분석·논증을 전개하며, 후반부(과제/맺음말)에서 ~해야 한다/~필요가 있다/~요구된다 당위 표현이 급증하는 구조적 전환이 양 문서에서 일관되게 나타난다.

3. **'따라서' 중심의 인과적 논증 스타일**: 따라서(인과결론)가 가장 빈번한 전환어이며, 즉(부연), 나아가(심화), 하지만(대조)과 결합하여 연역적 논증을 구축한다. 이는 정책 리뷰의 deductive reasoning 특성을 반영한다.

4. **다층적 열거 구조**: 과제/제안은 "첫째~넷째" 서수사 나열, 기능 설명은 ①②③ 원문자 나열, 전략은 글머리표/번호 나열을 병용하여 가독성과 체계성을 동시에 확보한다.

5. **한자어 75% 기반의 정책 레지스터**: 도모하다, 제고하다, 부합하다, 고도화하다 등 한자어 동사와 적정성, 타당성, 실효성 등 한자어 명사가 핵심 어휘를 구성하되, 꾸준히, 면밀히, 적극적으로 등 고유어/한자어 부사로 문체에 자연스러움을 부여한다.

6. **법률·통계·학술 인용의 3중 근거 체계**: 법률은 「꺾쇠」 인용, 통계는 수치 병기(N개소, N%), 학술 문헌은 통합형·비통합형 혼용으로 인용하며, 시각 자료(그림/표)를 높은 밀도(1.5~2p당 1개)로 통합한다.

7. **수미상관(首尾相關) 프레이밍**: 서론의 핵심 문장을 맺음말에서 변주 반복하여 문서 전체를 하나의 논지로 감싸는 구조를 사용한다. 이는 정책 리뷰에서 메시지의 일관성과 강조를 위한 전략적 기법이다.
